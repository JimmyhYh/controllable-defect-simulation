# 项目成果分级清单

**显示屏缺陷检测：可控缺陷生成与真实工业数据验证**

整理日期：2026年10月27日。本文件取代 `项目进展与可交付成果清单_20261026.md`（该文件保留为 10-26 快照）。
用途：私人设备、公开资源、个人学习与非商业研究；公司内部材料保持隔离。

本文只做汇总与分级，不新增实验。整理过程没有训练、模型前向、生成、校准或重算任何 AP/AUROC；所有数值直接引用已封存的指标、核验记录或报告正文。旧数据、权重、阈值、配置、失败现场与图件一律未改动。

## 一、一页结论

**这个项目有两个层次的结果，价值完全不同。**

第一个层次是**前八轮**：全部围绕"合成缺陷能否提升检测"这一命题做对照实验，四条路线（DRAEM 生成、可控生成、真实参考驱动、少样本合成补充）全部走完，**没有一条在真实留出上给出稳定增益**。这一层的产物是负面结论加工程资产。

第二个层次是**受控探针主线**（10-26 至 10-27）：换了一个问题——不问"能不能提升"，而问"这个检测器到底能看见什么"。这条线**给出了三条成立的结论**，第一次能把此前的零增益归因到具体机制上。

**最硬的三个结论**：

1. 在 AnoLCD 真实显示屏上，真实缺陷的 SEMU 中位 **8.21**，而该检测器的 90% 检出点只需 **4.58**——**缺陷整体落在可靠检出区内，并不"难"**。"合成没用是因为缺陷太弱"这条解释被证伪。
2. 把输入分辨率从 256 提到 512（同一覆盖密度），**五类缺陷的 AUROC 全部持平或下降，整体 −0.92 pt**。"采样不够细"这条解释被排除。
3. `spot` 一类的失败有明确机制：它在特征图上只占 **0.35 个位置**，而其余三类占 1.86—3.04；且"面积 × 对比度"与召回**严格单调**（731 / 287 / 148 / 28.5 对 1.000 / 0.979 / 0.897 / 0.562）。这是尺度门槛，不是数据量问题。

**推论**：在 AnoLCD + 无监督 PatchCore 上，已排除的两条路径都不在数据侧，**补充缺陷样本（真实或生成）对它们无效**。这比"效应在噪声内"要硬——那是测不出来，这是排除了通路。

## 二、分级标准

本项目里"有数字"和"能引用"是两件事。分级依据四条，缺一即降级：

| 判据 | 含义 |
| --- | --- |
| **前置验证** | 复现对照是否通过（如 256 档 τ 是否等于冻结值、spot 召回是否复现 0.562） |
| **判据预设** | 判定规则是否在运行前写死，而非看到结果后解释 |
| **评价池关系** | 评价池与训练池/生成池是同一池、同源、还是独立 |
| **效应/噪声** | 效应量相对初始化离散或样本波动是否可分辨 |

据此分四档：

| 档 | 名称 | 用法 |
| --- | --- | --- |
| **A** | 成立结论 | 可直接写进对外材料；附注其域与设定即可 |
| **B** | 可复用资产 | 代码、协议、管线；可直接用于新实验 |
| **C** | 有条件结论 | 内部可用，对外必须连同边界一起写 |
| **D** | 仅参考 | 不得作为证据；只能用于内部判断方向 |
| **E** | 不成立 | 记录性，防止后来者误引 |

## 三、A 档：成立的结论

### A1｜真实缺陷的可探测性标定（阶段 2a + 2b）

| 项 | 值 |
| --- | --- |
| 真实缺陷 SEMU 分布 | 中位 **8.21**，IQR 5.65—18.87（mura，n=47）；全类型中位 7.15 |
| 检测器检出点（mura_med，S=24.6 mm²） | SEMU_50 = **1.69**，SEMU_90 = **4.58** |
| 判读 | 8.21 > 4.58 → **缺陷在可靠检出区内**（判据 B 分支） |
| 前置验证 | 256 档 τ = 1.8928574562072753，与冻结值完全一致 |

**可以说的**：在这批数据上，「合成补充没有增益」**不能**由"缺陷太难、接近可探测极限"解释。

**必须带的边界**：仅 AnoLCD + 该 PatchCore 实例；背景取自 `test/good`，属历史 Tfinal（L2）；区间为背景重采样的百分位区间，非 MIL-HDBK-1823A 的严格 a90/95。

### A2｜分辨率不是 spot 失败的原因（阶段 3）

| 项 | 256 | 512 | Δ |
| --- | ---: | ---: | ---: |
| 覆盖密度 | 1.00% | 1.00% | 相同 |
| 整体 AUROC | 0.9086 | 0.8994 | **−0.009** |
| spot 召回（2a 口径） | 0.5616 | 0.5297 | −0.032 |
| 各类 AUROC 变化 | — | — | −0.020 至 0.000 |

**可以说的**：在覆盖密度相同的干净对照下，512 输入不改善任何一类。

**必须带的边界**：只到 512；1024 因建库内存 9.7—16 GiB 未执行，故只能说"512 档不改善"，不能推广到"任何更高分辨率都不改善"。

**方法学副产物（也有价值）**：对照实验必须控制**覆盖密度**而非核心向量的绝对值。首次执行固定 819 核心使密度降到 1/4，导致整体退化 −1.73 pt、τ 漂移 +19.2%；恢复密度后收窄到 −0.92 pt、+5.8%。这次自证是"控制错了变量"的完整案例。

### A3｜spot 的尺度门槛机制（10-27 只读分析）

| 类型 | 面积 mm² | \|Cx\| % | 面积×对比度 | 特征占位 | 召回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| scrathes | 55.12 | 13.26 | **731.1** | 2.62 | 1.000 |
| mura | 27.68 | 10.36 | 286.9 | 1.86 | 0.979 |
| line | 74.24 | 2.00 | 148.2 | 3.04 | 0.897 |
| **spot** | **0.96** | **29.72** | **28.5** | **0.35** | **0.562** |

两条一致性检验：
- 按"面积×对比度"排序 = 按召回排序，**完全一致**；按 SEMU 排序**完全反向**。
- 特征占位 ≥1.86 的三类召回 ≥0.90；唯一 <1 的 spot 召回 0.56。门槛落在 1.0 附近。

**相位假说被否定（重要）**：若失败源于落在网格间隙，召回应与 GT 质心 mod 8 相关。实测四分位召回 0.619 / 0.581 / 0.597 / 0.619，**无趋势**。原因是 spot 始终不足 1 个位置，3×3 平均对它是均匀稀释。否定"运气"解释，支持"池化稀释"解释。

**可以说的**：spot 不是"更难的同类缺陷"，是跨过尺度门槛的另一类；高对比度（四类最高）无法补偿小 29 倍的面积。

**必须带的边界**：机理推断基于"面积×对比度"这一代理量与特征占位的几何折算，未做 patchsize 单因素对照，故属**有数据支撑的解释，非已证实机制**。

### A4｜生成路线在真实显示屏上失效

AnoLCD display 1100 张，同一批数据、同一评价口径：

| 模型 | 像素 AP | 整图 AUROC | 召回 |
| --- | ---: | ---: | ---: |
| PatchCore（不用缺陷样本） | 85.83% | 90.86% | 84.67% |
| DRAEM-A（生成） | 13.98% | **49.95%** | 2.13% |
| DRAEM-B（生成） | 15.64% | **50.37%** | 3.73% |

**可以说的**：A/B 的 AUROC 与随机排序无异，即生成路线在该设定下未收敛到可用状态。B−A 的 +1.66 pt 是在基线本身失效背景下的差，不构成方法有效性证据。

**必须带的边界**：两者监督设定不同（PatchCore 用 2400 正常图；A/B 用 5 张真实异常 + 合成），故不能据此说"PatchCore 方法更优"。

### A5｜少样本合成补充的效应不可检测（两轮）

| 轮次 | ΔAP 均值 | 离散度 | t（df=2） |
| --- | ---: | ---: | ---: |
| 随机初始化 | +1.7513 | 样本 SD 3.4008（n=3 初始化） | ≈0.89 |
| 预训练单头配对 | +0.7771 | 配对 SD 1.2755（n=3） | ≈1.06 |

**可以说的**：两轮效应量均小于初始化噪声，且方向不稳定（配对轮含 −0.4282）。按 n=3、SD≈1.28 计算，检出 1 个百分点需约 13 对，两轮均未达到该设计强度。

**必须带的边界**：SD 由 3 个样本计算，不是置信区间；三对共享同一 R5 与评价划分；B 臂同时改变了正负曝光组成与阳性像素量。

### A6｜SSN 严格 R5 的 gate 结构与诊断结论

| 项 | 值 |
| --- | --- |
| 特征 AP | 99.9156%（21 张训练图同池，非留出） |
| 逐例最低 | 99.6481% |
| 分类（严格 >0.5） | TP5 / FN0 / FP10 / TN6 |
| 联合 gate | **false**（FP ≤1/16 未通过） |
| 诊断结论 | 无单一根因；仅剩"分类卷积 BN 统计来源敏感性"，且双向（FP 10→8），提案自述即使修好 gate 仍 false |

**可以说的**：SSN 方向停止不是模型能力不足，是**验收结构不可通过**——固定 `sigmoid > 0.5` 是本项目自加的工程门槛，与 focal loss 未校准 sigmoid 不兼容；而 gate 是正式训练入场券，形成闭环。

**必须带的边界**：99.9156% 是同池拟合，既未被否定也未被兑现；原 false 保留，不得改写。

### A7｜真实参考驱动生成卡在素材，不在算法

v1：暗底 Mura 参考配到亮底带点阵背景。v2：两张固定背景含 T 形刻度与规律圆点阵，视觉门未过。v3：收紧到局部 24 位置，仅 3 个通过。

**可以说的**：三版实际生成请求均为 **0**。瓶颈是同域背景素材，不是渲染算法。这与 NDT 文献中"virtual flaw 优于纯模拟缺陷"的结论一致——方向对，素材缺。

### A8｜POD 标准口径落地（10-27，替代原插值）

检出点改由 hit/miss Probit GLM 估计（横轴取实测 SEMU），按背景聚类 bootstrap 2000 次，输出 a50 与 a90/95。

| 形态 | a50 | a50 CI95 | a90 | **a90/95** |
| --- | ---: | --- | ---: | ---: |
| mura_p25（S=8.0） | 3.83 | 2.77—5.20 | 12.40 | **10.26** |
| mura_med（S=24.6） | 1.85 | 1.24—2.55 | 5.04 | **3.80** |
| mura_p75（S=72.3） | 1.90 | 1.19—2.60 | 4.41 | **3.30** |
| line_med（S=73.6） | 不可估 | — | 2.90 | 1.88 |

三路验证均通过：参数恢复自检（β 误差 0.096、a50 相对误差 3.9%）、换 logit 连接函数（a50 差 0.01—0.10）、用名义档位复现旧插值（mura_med 1.73 vs 1.69，差 0.03）。

**可以说的**：与旧插值的分歧不是实现错误，而是插值法缺陷——分段线性插值在平台/陡变处给出的是"第一个跨过 0.5 的档位"，不是估计。`mura_p25` 曲线在 2.5→4 有平台（0.407→0.404），插值被推到 6.37；MLE 给 3.83。

**必须带的边界**：`line_med` 各档检出率最低已 0.667，a50 为外推，标 `a50_identifiable=false`，不作能力下限引用。同档位内实测 SEMU 跨 2.3—3.0 倍，a50 不得单点引用。

### A9｜同源效应的边缘维度已被实验排除（10-27）

严格配对实验：对 1107 条刺激逐条配对，保持同一背景、位置、有效面积、平均对比度，**仅改边缘剖面**（软边 → 硬边）。配对精度 S 误差中位 2.27e-16、Cx 误差中位 2.2e-07。

| 形态 | 软边 | 硬边 | Δ |
| --- | ---: | ---: | ---: |
| mura_p25 | 0.757 | 0.753 | −0.003 |
| mura_med | 0.745 | 0.780 | +0.035 |
| mura_p75 | 0.741 | 0.828 | +0.088 |
| line_med | 0.817 | 0.801 | −0.016 |
| **整体** | 0.7633 | 0.7895 | **+0.0262** |

判据 `no_evidence`：改硬边后响应不降反略升，最高档全为 1.000 → 1.000。基线误报 2/60 → 2/60 完全一致。

**可以说的**：G1 学到的是"局部亮度突变"这类更一般线索，不是某一种软边剖面。这同时否掉了"G1 的 76.3% 只来自记住软边"这一具体推测。

**必须带的边界**：同源效应**未被排除，只是定位到别处**——形状家族、位置、尺寸三个维度仍与训练一致。故 G0/G1 的能力卡数值仍不能读作"学到了可迁移表征"。

### A10｜补样本判据四个分支都有实例（10-27）

| 分支 | 条件 | 实例 | 结论 |
| --- | --- | --- | --- |
| A1 | a50 > 真实中位，占位 ≥ 1 | **无** | 对比度不足 → 补样本可能有效 |
| **A2** | a50 > 真实中位，占位 < 1 | **spot_xs** | 面积过小、特征不可表达 → 补样本无效，应改结构 |
| B | 真实中位 > a90/95 | PatchCore / mura | 缺陷在可靠检出区内 → 归训练侧 |
| C | 介于两者 | G1（8.43 压在 8.21 上） | 过渡区 |

A2 实例来自新增 spot 形态探针（椭圆半轴 1.4 px，实测 S = 0.800 mm²，真实 spot 0.96）：8 档检出率 0.176 / 0.200 / 0.106 / 0.234 / 0.362 / **0.426 / 0.426 / 0.426**——最高档 42.6%，10/16/25 三档完全持平。a50 不可估，下界 > 26.22（数据上界），真实 spot 中位 11.64 < 26.22 → 落 A；占位 0.315 < 1 → A2。基线误报 6/60，与阶段 2b 完全相同。

**可以说的**：判据从"半验证"变"四分支俱全"。且 A 分支以 A2 而非 A1 触发——若当初未细分，会给出"对比度不足 → 补样本可能有效"的错误对策。

**必须带的边界**：本形态 S 比真实 spot 小 17%，非逐图配对，只能量级对齐（方向保守）；曲线 2.5 档低于 1.0 档属二项噪声（n=47）；严格说 5.1（曲线跨越）未通过，故用下界判定而非 a50 点值。**A1 仍空**。

## 三之二、能力卡（10-27，五行）

| 检测器 | 监督 | 训练异常来源 | 冻结 τ | 基线误报 | 总检出 | 最高档 | a50 / a90-95 |
| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| PatchCore | 无监督 | 不用异常 | 1.892857 | 10.0% | **84.7%** | 100% | 1.85 / **3.80** |
| G1 | 有监督 | 可学习生成 | 0.715590 | 3.3% | 76.3% | 100% | 3.32 / 8.43 |
| G0 | 有监督 | 参数化渲染 | 0.612454 | 5.0% | 19.9% | 48.9% | 不可估 |
| DRAEM-B | 有监督 | 真实异常 + 合成 | 0.999560 | 6.7% | 10.8% | 28.6% | 不可估 |
| DRAEM-A | 有监督 | 真实异常 + 合成 | 0.999304 | 3.3% | 5.4% | 14.3% | 不可估 |

**可以说的**：PatchCore 与 G1 总检出只差 8.4 pt，但 a90/95 差 **2.22 倍**——只看总检出率会误判两者能力接近。无监督的 PatchCore 完胜全部有监督模型。

**必须带的边界**：G0/G1 为跨域测量（训练在渲染背景、刺激在真实背景），须单独标注；DRAEM 判 `no_response`（最高档 < 50%），其低误报是"几乎不出警"的结果，不能读作判断更准；三者 score/τ 分属距离尺度与 softmax 域，不可比。

## 五、C 档：有条件结论

| 结论 | 数值 | 必须附带的边界 |
