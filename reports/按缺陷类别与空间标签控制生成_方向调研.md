# 按缺陷类别与空间标签控制生成：面向专家筛选的方向调研

日期：2026年11月5日。范围：代表性论文、官方页面、作者仓库及既有项目研究的定向调研，非穷尽性综述。仅整理研究判断；未查看新数据图像、下载模型／数据、安装依赖、生成、前向、训练或评价。私人设备公开资源，仅个人学习与非商业研究。

## 1. 带教需求对应的研究任务

目标是：给定缺陷类别、正常背景、位置／区域和必要的外观参数或真实参考，生成若干带标签的候选，由专业人员判断是否保留。专家负责真实性与业务适用性；生成工具负责条件明确、输出可追溯、候选易于比较。

这不要求先自动学会专家的筛选标准，也不必先取得检测提升。需要区分三个层次：请求属于哪一类、实际画出了什么、专家最终确认属于哪一类。生成请求写了某类别，不代表输出已得到该类别的专家认可。

推荐把研究问题表述为：**能否按指定缺陷类别和区域生成外观可变化、背景可保留、标签可核对的候选，支持专家筛选？** 这是本次需求解读，尚非已通过的实验结论。

## 2. “标签”至少包括两种

| 标签／信息 | 含义 | 不能据此声称什么 |
|---|---|---|
| 请求类别 | 本次希望生成的缺陷类别 | 不能证明生成结果就是该类 |
| 专家确认类别 | 专家对输出的确认；允许待定／拒绝 | 不等于物理成因得到验证 |
| 条件区域M_roi | 允许编辑或希望生成的区域 | 不是自动可靠的像素真值 |
| 实际变化区域M_eff／软变化强度 | 输出相对同一输入背景的变化支持域／幅度 | 对扩散生成，不能把所有变化都叫缺陷 |
| 审阅后空间标注 | 专家认为可见缺陷所在区域；可修订候选掩码 | 模糊边界可能存在不确定性 |
| 实例信息 | 一张图中各缺陷分别的类别与区域 | 首版可限制单实例，避免混合标签歧义 |

“类别＋位置”是不同控制维度。给定文本类别但位置随机，不满足完整需求；只有二值异常掩码而没有类别，也不满足按类生成。

对参数模拟，可由同背景差分获得实际残差及阈值支持域，并同时保存连续残差。对扩散补绘，模型可能修改亮度、纹理和背景，差分只能帮助审阅，不能直接作为可靠的缺陷语义标签。若另加区域外硬复合，应注明它是工程约束，仍需观察接缝与局部合理性。

## 3. 可参考的方法

以下排序依据本项目需求契合度与实施风险，是研究判断，不是论文效果排名。

### 3.1 现有参数化模拟：保留为可解释基线

已有位置、范围、亮暗、形状、尺寸及种子控制可复用。适合先输出“块状亮度不均模拟”“线状亮／暗扰动”等明确的外观类别，以及实际残差和掩码。类别从生成机制获得，几何与背景保留便于检查。

限制是外观拟真度。不能把“线状暗扰动”直接等同于划伤，或把某种亮度函数等同于已验证的Mura物理机理。缺陷业务命名和可接受外观需专家确认。旧成果可参考[可控模拟报告](D:/华兴源创/报告/可控Mura与线状缺陷模拟两周研究报告.md)，本次未重验旧结果。

### 3.2 AnomalyDiffusion：类别外观与空间条件分离

Hu等，AAAI 2024。以学习的异常外观嵌入和掩码编码的空间嵌入分离两类条件，配合注意力重加权改善图像与掩码对应。适合借鉴“同类外观＋指定掩码”的组织方式。作者公开异常／掩码训练与生成入口；不是无需适配即可生成屏幕缺陷的模型。

原文定位：摘要与Spatial Anomaly Embedding／Adaptive Attention Re-weighting方法部分。[论文](https://arxiv.org/abs/2312.05767)、[作者代码](https://github.com/sjtuplayer/anomalydiffusion)。需要少样本学习、旧环境适配；改变强度并不自动获得物理准确的严重度标签。

### 3.3 TF-IDG：真实参考驱动的免参数训练候选

Xu等，ICCV 2025。使用单个异常参考，结合特征对齐、自适应异常掩码和纹理保留生成候选。适合优先核对“参考类别与目标区域”的接口。免训练指无需更新模型参数，不代表无梯度计算、无大模型或低资源。

原文定位：摘要、方法模块及Fig.1。[论文](https://www.openaccess.thecvf.com/content/ICCV2025/papers/Xu_Training-Free_Industrial_Defect_Generation_with_Diffusion_Models_ICCV_2025_paper.pdf)、[作者代码](https://github.com/rubymiaomiao/TF-IDG)。README要求AnyDoor与DINOv2权重；当前推理脚本默认GPU路径并包含可选掩码细化依赖。对本设备的显存、完整权重、许可和标签一致性未完成准入，故仅为候选。

### 3.4 DefectFill：少样本类别学习与指定形状补绘

Song等，CVPR 2025。以少量缺陷图／掩码适配补绘模型，缺陷、对象及注意力目标共同约束局部生成；Fig.1直接展示在给定形状中填入学习到的缺陷。§3.3还有低保真候选筛选，可参考其“生成后筛选”组织，但算法筛选不能替代专家确认。

[原文§3.2—3.3、Fig.1与局限](https://arxiv.org/html/2503.13985v2)。本次未核实到可直接采用的作者完整实现；检索到的[axelsig1仓库](https://github.com/axelsig1/DefectFill)明确自称非官方，并存在会议年份表述差异，不能当作者复现承诺。优先作为方法依据。

### 3.5 MAGIC：掩码引导与背景／缺陷分区控制

Choi等，arXiv:2507.02314；当前v6页面标注CVPR 2026 Findings，不能与旧笔记v1的设置混写。方法采用补绘、提示扰动、空间自适应引导和上下文感知掩码对齐，适合参考类别内多样性与区域约束。

[v6摘要与方法概述](https://arxiv.org/abs/2507.02314v6)、[作者代码](https://github.com/Jaeihk/MAGIC)。上下文对齐会迁移掩码；若用户指定位置优先，需要明确这一能力与原方法的冲突，不能无说明自动移位。是否采用独立适配须另定，当前不授权训练。

### 3.6 SeaS：带掩码的数据生成参考，非首选固定局部编辑接口

Dai等，ICCV 2025。正常／异常分离学习、共享生成网络，再用精炼掩码预测分支输出像素标注，适合参考多类别数据组织与图像—掩码配套。其掩码主要是生成后的预测输出，不能默认理解为严格服从用户给定区域或形状。

原文定位：§3.3—3.4、§4.1；[论文](https://arxiv.org/abs/2410.14987)、[作者代码](https://github.com/HUST-SLOW/SeaS)。作者设置包含正常样本与带掩码异常，训练分生成和掩码阶段；当前不建议把整套训练作为首项。

### 3.7 AnomalyControl：注意同名论文

He等的 *Learning Cross-modal Semantic Features for Controllable Anomaly Synthesis* 使用图文参考条件引导生成，适合了解类别语义和参考外观如何结合。[原文摘要与方法](https://arxiv.org/abs/2412.06510)、[作者仓库](https://github.com/DaniellaHe/AnomalyControl)。本次查看README的预训练模型栏仍为Coming soon，不能认定完整模型可直接使用。

它与Ali等IEEE Access 2024的 *Few-Shot Anomaly Generation by ControlNet Inpainting* 是两项不同工作。后者将异常生成表述为正常图上的ControlNet补绘，[大学官方条目与DOI](https://cris.unibo.it/handle/11585/1009680)。后续文献表应同时写题名和作者，避免混用其资源、训练需求或结论。

## 4. 推荐方向与必要备选

**主方向：类别条件＋区域条件＋可追溯候选输出；以现有参数模拟作基线，以少量真实参考的局部迁移／补绘作外观增强候选。** 不把纯文本随机出图作为主线，也不把检测器的异常分数当类别标签。

方法优先级：先对TF-IDG做独立资源／输入输出／类别对应核验；若其重量或标签接口不合适，回到既有参考迁移基础，而不是无条件安装／换模型。DefectFill、AnomalyDiffusion提供后续少样本学习的依据，MAGIC提供掩码与多样性约束思路；SeaS暂作为比较方法。此优先级是有条件判断，尚未固定模型或承诺本地可运行。

必要备选：继续参数模拟和参考图块几何迁移。前者解释生成机制，后者保留参考中的可见形态；两者都需专家看是否自然。参考图块包含原背景时，变换与融合可能迁入背景差异，不能未经配准声称提取了纯真实缺陷残差。

现有坐标、保护域、实际残差、掩码及种子基础仍有价值。旧背景适用性失败、3/24通过等证据继续保留；它们说明背景／上下文条件需要审阅，不能因新方向而直接恢复原48请求验收。

## 5. 首版应怎样组织类别与候选

建议把“外观类别”与“物理成因”分开。可先用块状亮度不均、线状亮度扰动作为公开研究的暂定外观类别；亮／暗、尺寸、方向、幅度作为属性。专家后续给出业务类别映射。不能从一张线状图推断其一定是划伤、压痕或线路故障。

类别词典可以很小：类别ID、名称、可用参考及其来源、允许属性。候选只需附生成请求类别、背景／参考ID、区域与掩码、参数／seed、生成器版本，以及保留／拒绝／待定和可选一句理由。不要求专家填写长表，也不要求先提供完整自动筛选规则。

单个请求保持背景／类别／位置固定，通过seed等改变外观，适合“抽卡”式审阅。应能同时查看原图、候选、掩码叠加和实际变化；显示增强若用于观察弱缺陷，应与原始对比度图并列且明确标注，不能增强后覆盖原图。

请求类别与专家确认类别分别保存。专家拒绝或认为类别不符时，保留失败含义，不把请求类别硬写成最终真值。若供后续检测训练，必须一并确认空间标签是否可用；一个“保留”按钮不能自动证明像素掩码准确。

## 6. 如何判断生成能力是否成立

应先看候选生成，而非立即再跑六组检测训练。需要分别展示：类别是否可辨、区域／形状是否遵循、背景是否保留、标签是否对应实际缺陷、同类是否有变化。自动核验可检查文件／类别字段、几何与越界、残差、掩码空缺等；真实性和业务类别仍交专家。

展示需包括固定请求全部候选和无效数，再标记专家选择；仅展示专家留下的图时必须注明筛选分母。专家选出的样本集可作为最终交付，但不能据此声称未经筛选生成全部可靠。专家保留率还依赖专家、类别与背景，不能直接当通用逼真度指标。

后续如研究训练价值，再独立设计筛选前／后及纯真实对照，控制训练预算并报告样本构成；评价材料不得作为生成参考或由检测成绩反向选候选。当前不启动此分支。

## 7. 尚未解决的条件与下一步

当前缺口是专家认可的初始类别命名和少量可作为该类外观锚点的参考，以及候选方法在私人设备上的完整准入。此前报告的8GB设备信息属于历史快照，本次未查询实际可用RAM／VRAM，不能给出可运行保证或固定耗时。论文在MVTec／VisA上的结果不能代替屏幕验证。

本次仅浏览原文与源代码网页并阅读旧研究文字；未获取权重、执行作者代码或更改旧成果。TF-IDG论文页面曾有一次403，后续通过CVF的www页面与作者仓库核对；未据搜索摘要认定完整实现兼容。代码许可证与模型／编码器／数据使用条件需分别核验。

**唯一建议的下一步：另做“类别条件与标签接口可行性核验”——从现有公开材料的元信息确认能否建立两类外观类别与参考来源，再静态检查TF-IDG及既有生成基础是否能接受类别／参考／目标区域并输出可核对标签；列出资源缺口和停止条件。只核验，不自动开发、下载、生成或训练。** 在此之前不改旧执行计划或冻结协议，本文件是方向调研成果。
