# 预训练单头分割严格R5基线研究报告

**整理日期：2026年10月23日。研究范围：私人设备上的公开KolektorSDD2数据、个人学习与非商业研究。**

本报告整合已封存的纯真实训练、正常校准、真实评分、CPU指标核验及图件，不增加实验或更改原结果。对应[分阶段执行计划](D:/华兴源创/计划/预训练单头分割严格R5基线执行计划.md)与[独立实现设计](D:/华兴源创/计划/预训练单头分割严格R5基线实现设计.md)。

## 摘要

本轮建立了一个仅用5张真实异常图及固定正常训练池的预训练单头分割基线，用来为后续合成训练研究提供明确的模型与评价起点。模型采用SMP U-Net和ImageNet ResNet18编码器，固定编码器BN运行统计、微调其affine参数，以GN8替换解码器BN，使用有效域CE＋Dice训练。正式实验只有一个初始化seed，完成10000次更新；不使用合成、U241或Q200训练，不加载训练侧小试权重初始化正式模型。

最终模型经Q200正常图校准，冻结原阈值τ=7.264203168233501e-06。在历史已见的同一E1004上，全局精确像素AP为43.65305632%，整图AUROC为85.71842587%；原阈值下TP81、FN29、FP52、TN842，即异常召回81/110=73.63636364%、正常误报52/894=5.81655481%。实际评价包含110张异常、894张正常、146,411,528个原生像素及486,461个阳性像素。

结果形成了来源、分母和运行口径完整的探索性基线，也保留了明显的漏检和误报。训练侧21窗高AP只表明固定小池可拟合；完整性核验只说明保存结果与协议一致。单seed、固定R5与划分、单类别、未知采集分组及E历史已见，使本轮不能支持稳定增益、预训练单因素因果或真实屏幕效果结论。

## 1. 研究目的与成果边界

本轮直接回答的任务是：在严格R5数据边界内，建立可复核的纯真实预训练单头定位基线，完整保留正常校准与真实评价中的错误。这里的“预训练”指通用ImageNet编码器初始化，缺陷定位能力仍由本轮监督训练获得，并非直接使用已训练好的工业缺陷检测器。

本轮完成独立环境与通用权重取得、固定训练窗小试、正式纯真实训练、Q200校准、E1004评分及CPU指标、固定样例图件。没有进行合成训练、参考生成、第二骨干或多seed正式实验。旧SSN、随机初始化GN分割及可控模拟研究均保留历史含义，不用于替换本轮失败例、调阈值或选择中间权重。

## 3. 模型、训练与整图评分

### 3.1 固定来源与单头结构

采用SMP v0.5.0的U-Net，固定作者commit `420ce84b0c2df0286fa9bb2bd1499eea625c9b33`；ImageNet ResNet18通用编码器来自`smp-hub/resnet18.imagenet`，固定revision `3f2325ff978283d47aa6a1d6878ca20565622683`。来源与许可依据见[本地来源清单](D:/华兴源创/实验/弱缺陷Demo/vendor/SMP_0_5_0/SOURCE_MANIFEST.json)、[资源协议](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/resource_preparation/protocol.json)及[实际取得身份](D:/华兴源创/实验/弱缺陷Demo/models/pretrained_segmentation/resources_v1/acquisition.json)；对应固定官方版本为[SMP源码](https://github.com/qubvel-org/segmentation_models.pytorch/tree/420ce84b0c2df0286fa9bb2bd1499eea625c9b33)和[编码器资源](https://huggingface.co/smp-hub/resnet18.imagenet/tree/3f2325ff978283d47aa6a1d6878ca20565622683)。

模型输入RGB三通道，编码器深度5，解码通道依次256／128／64／32／16，最近邻上采样，无attention或辅助分类头。输出为同一分割头的正常／异常两通道logit，取softmax异常通道作为概率；“单头”不等于单通道sigmoid。整图分数直接由分割概率导出。

编码器20个BN的运行均值、方差及计数保持固定，affine参数仍可训练，编码器其余参数也参与微调；这不是冻结整个编码器。解码器10个BN独立替换为GN8，affine开启、eps=1e-5。该适配是本工程包装，不称SMP原生GN配置。

通用权重显式从本地safetensors加载，不触发自动下载。依据实际header，仅移除`fc.weight`和`fc.bias`，为20个缺失的旧版BN计数项补初始0；其余缺项或多余项均拒绝。正式模型从同一通用编码器与新解码器／分割头初始化，不使用probe、SSN或旧任务权重。源码MIT与骨干模型卡`license: other`分别保留，未将源码许可外推为无限制权重使用授权；使用条件沿用已保存审计和个人非商业范围。

### 3.2 损失、请求与最终权重

RGB保留原始对比度，按uint8/255后使用ImageNet均值(0.485,0.456,0.406)、标准差(0.229,0.224,0.225)归一化。原生图像不缩放；GT二值且不膨胀。损失为有效域内无类别加权的像素CE均值，加异常通道Dice损失：

\[
L=L_{CE}+1-\frac{2\sum_{i\in V}p_i y_i+1}{\sum_{i\in V}p_i+\sum_{i\in V}y_i+1},
\]

其中V排除补边，p为异常softmax，y为二值GT。正常空GT也参与CE与Dice；本分支无重建或SSIM损失。

| 设置 | 正式实际口径 |
| --- | --- |
| 初始化seed／最终预算 | 2026102202；10000次更新，只使用最终权重 |
| 请求组成 | 奇数步R、偶数步N；真实异常5000次、正常5000次，无合成 |
| R采样 | R5洗牌循环，每图1000次；抽合法非空GT窗 |
| N采样 | N1885内均匀有放回选图及合法窗 |
| 增强 | RGB／GT／有效域同步水平与垂直翻转，各p=0.5；实际4912／4947次 |
| 资源规格 | FP32、batch1、workers0，无AMP、梯度累积或梯度裁剪 |
| 优化器 | Adam；encoder 1e-5，decoder＋head 1e-4；betas=(0.9,0.999)、eps=1e-8、weight_decay=0 |
| 日程 | 更新1—8000：1e-5／1e-4；8001—9000：2e-6／2e-5；9001—10000：4e-7／4e-6 |
| 保存与恢复 | 每1000步一个自有完整保存点，共10个；实际未续训，GPU完整恢复尚未实测 |

训练请求与模型随机流分离：PCG64／SeedSequence的namespace0负责R循环及窗口、namespace1负责N、namespace2负责翻转。模型、优化器、请求游标、下一步LR、Python／NumPy／Torch CPU及CUDA随机状态均纳入自有恢复身份。8000／9000是完成更新后衰减，不能提前一更新。

正式最终权重见[final_weights.safetensors](D:/华兴源创/实验/弱缺陷Demo/models/pretrained_segmentation/ksdd2_r5_v1/baseline_2026102202/final_weights.safetensors)，SHA256为`f8f4f94029da49704c5d2b194c549dd24ef364a7f7d365ff6fcef9e3f373e454`。10000步、10保存点、请求曝光、日程、有限性及固定BN的核验见[正式训练核验](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/baseline_training_verification_v1/verification.json)。

### 3.3 原生整图拼回与校准

整图按原生256×256窗口评分，纵向stride128，并加入H−256尾窗，坐标排序去重。右侧不足256宽使用反射补边，预测后先剔除补边。各窗按y升序在原生坐标FP32累加，再按覆盖次数等权平均，保存H×W原始float32异常softmax图。没有评分期增强、概率拉伸、平滑或测试池归一化。

整图分数为**保存原生拼回概率图的最大值**。评分函数不接收GT；Q与E实际评分前后参数签名一致，BN buffer保持正式初始化／最终签名。4270个E窗口在拼回后对应1004张图，重叠像素仅以拼回后的一个值进入指标，右补边不进入分母。

Q200按固定顺序各评分一次，共844个窗口；以原生float32最大值转float64计算q=0.95、`linear`分位数，冻结：

\[
\tau=7.264203168233501\times10^{-6},\qquad \widehat{z}=\mathbf{1}[s>\tau].
\]

等于阈值判正常。Q同池FP10／TN190，分母200；这是阈值构造池上的计数，不能称独立验证或未来误报率保证。阈值很小不表示物理缺陷强度或经过概率标定的置信度，不能凭热图观感改用0.5。原阈值与原规则保留，见[threshold.json](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/normal_calibration_v1/threshold.json)及[Q200独立核验](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/normal_calibration_verification_v1/verification.json)。

## 4. 实际结果与证据层次

### 4.1 固定训练窗技术验收

小试seed2026102201完成2000步、5个保存点，仅用最终权重评价固定R5五窗及旧N16十六窗：21张独立训练图／窗、1,225,984有效像素、24,482阳性像素。全池精确AP=99.99696542%，全部5个R窗AP均超过0.85，原全池AP≥0.95及有限性、状态不变、异常图非常量条件通过。其全局AP与sklearn交叉核对绝对差3.33e-16，并核对实际ties。

这说明给定模型与训练包装能够拟合固定小池，不能转写成新图定位效果，也不能把小试gate当作正式E性能达标线。本轮不套用旧SSN分类sigmoid>0.5门槛。原证据见[小试CPU验收与核验](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/probe_acceptance_verification_v1/verification.json)。

### 4.2 E1004完整真实评价

| 层次 | 冻结结果 | 实际分母与含义 |
| --- | --- | --- |
| 像素定位排序 | 全局精确像素AP **43.65305632%** | 146,411,528原生像素／486,461阳性；全局聚合，不平均逐图AP |
| 整图排序 | AUROC **85.71842587%** | 同一1004图，110异常／894正常；分数为原生max |
| 原阈值下异常判定 | **TP81／FN29**；召回 **73.63636364%** | 81/110检出，29/110漏检 |
| 原阈值下正常判定 | **FP52／TN842**；正常误报 **5.81655481%** | 52/894误报，842/894正确判正常 |

像素AP度量缺陷像素相对正常像素的排序，不是“43.65%的像素分对了”，也不是IoU或轮廓重合率。整图AUROC评价整图分数排序，不等于“85.72%的异常被检出”；实际召回由原阈值给出，为81/110。TP仅表示整图超过阈值，不保证缺陷轮廓准确。报告未增加像素阈值、IoU或显著性检验。

全局AP复用冻结`metrics.exact_ap`，以所有非负float32原值精确分组处理同分数：30,212,801个不同分数值、17,912,751个有重复的分数值，未抽样像素、使用近似区间或平均逐图AP。两份uint32磁盘表共8,522,825,736字节；实际N／P与独立保存表计数、ties不变量核对一致。21窗sklearn核验是既有算法依据，E没有再全量计算一遍sklearn AP。

实际GT在原CPU计算时核对来源hash、尺寸和二值后建立规范缓存；后续完整核验覆盖全部1004份规范标签及评分来源，确认实际110／894与486,461阳性，未取两类成功交集或删失败图。独立核验未重算AP／AUROC或重新读原GT，完整性通过不等于效果优秀。原数值见[metrics.json](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/real_metrics_v1/metrics.json)，全量证据见[real_metrics_verification_v1](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/real_metrics_verification_v1/verification.json)与[中文核验结果](D:/华兴源创/实验/弱缺陷Demo/results/pretrained_segmentation/ksdd2_r5_v1/real_metrics_verification_v1/第6阶段CPU真实指标核验结果.md)。

## 6. 讨论与唯一后续问题

### 6.1 目前得到的证据

本轮建立了来源和边界明确的纯真实预训练单头基线，并证明固定小池在当前实现下能够拟合。正式E结果则表明，这一版本仍有29/110异常未检出、52/894正常被误报，像素定位排序AP为43.65%。两层证据不能互换：小试高AP不能证明真实泛化，真实错误也不能单凭这一差距确定退化原因。

历史[少样本合成训练报告](D:/华兴源创/报告/少样本真实工业缺陷合成训练研究报告.md)中的随机初始化GN分割及A／B结果，可作为研究背景。不同轮次同时改变了结构、初始化、学习率、请求序列或曝光组成；历史三对初始化与本轮一个初始化的证据强度也不同。因此不将跨架构差异解释为预训练的单因素收益，不宣称当前模型在定位、整图排序和阈值误报上全面更好。旧SSN收束结论也不被本报告改写。

### 6.2 外推限制

本轮只有一个正式seed，没有多初始化稳定性或总体显著性证据。R5及数据划分固定，无法判断换一组5张真实异常后的敏感性；单一工业产品类别、未知采集分组也限制跨工件／跨域外推。大量相关像素、重叠窗口和图件页数不能替代独立数据集重复。

Q同池FP10/200不能称未见正常验证。E历史已见，其结果只能支持探索性描述，不能因本轮未在训练中调用E就称全新未见验证。本轮没有证明生成外观逼真、合成有效、稳定预训练收益或屏幕／Mura检测收益，也没有给出面向生产的漏检／误报验收结论。

### 6.3 唯一建议的后续研究问题

**在保持同一预训练单头结构、配对初始化、总更新预算和正常／异常曝光总量时，将部分重复R5异常训练槽替换为可控合成，能否在多初始化的探索中改善真实全局像素AP，同时完整呈现召回与误报代价？**

该问题由当前可拟合而真实定位仍有限、历史合成结果平均正增益但不稳定这两项证据支持，尚不是效果承诺。若另立方案，须匹配模型与曝光预算，预先冻结所有配对、最终权重和指标；替换R槽也改变真实／合成异常组成，结论只能归于该训练组成策略，不能拆出合成机制的单因素因果。沿用E只能作探索性评价，确认性外推仍缺新的独立真实证据。本报告仅提出问题，不启动合成、开发或三种子新实验。
