## 一、共同约束与验收关注

两类：class_id=1块状亮度不均、class_id=2线状亮度扰动，0为背景；polarity为bright／dark。不是物理缺陷成因标签，不自动命名为划伤／线路故障。专家未审confirmed_class=null。

单张单实例，先椭圆／不规则块、直线／预设折线；不做自由手绘、多实例或全参数随机。本轮无需AI／训练／统计拟合或检测成绩；不读取旧Q／S_bg／E／U及其他冻结评价图像、GT、概率，不改旧来源、源码、环境、配置、权重、库、tau、缓存或失败结论。

私人设备仅公开或个人获准图片，公司材料隔离。导入图片只作本地生成，不能自行改变数据角色。完整批次可只读核验复用；未知／部分目录停止保留，不自动补生成、清理或认领。

固定允许区域M_roi、类别、位置、尺度／方向与幅度，seed只控制区域内外观。区域外相对EXIF规范RGB及其无损PNG逐像素不变。原生尺寸生成，界面预览才可缩放。类别、请求区域、float变化标签和PNG变化标签分别保存。

重点核对：EXIF后坐标与留白映射；非方图／边缘越界；白底增亮和黑底变暗饱和；弱变化量化不可见；不同seed产生相同PNG。这些都必须如实展示，不能靠换样或增幅消除。

| 文件 | 职责与接口 |
|---|---|
| protocol.py | 类别／schema／参数检查，`validate_request(request: dict, height: int, width: int) -> dict` |
| inputs.py | `inspect_environment() -> dict`；`normalize_background(path: Path) -> dict`，返回rgb_u8、source_sha256、规范化元信息 |
| geometry.py | `build_roi(request: dict, height: int, width: int) -> dict`，返回M_roi和几何信息，不依赖seed |
| render.py | `render_candidate(rgb_u8: ndarray, geometry: dict, request: dict, seed: int) -> dict`，只计算不写文件 |
| labels.py | `measure_candidate(rgb_u8: ndarray, rendered: dict, class_id: int) -> dict`，派生残差、mask、类别图和状态 |
| batch.py | `generate_batch(config_path: Path, output: Path) -> dict`；`verify_batch(output: Path) -> dict`，独立事务与全候选导出 |
| review.py | `set_decision(batch_path: Path, candidate_id: str, decision: str, note: str = '') -> dict`，只改独立review文件 |
| gui.py | 本地窗口、缩放映射与候选浏览，调用上述核心 |
| cli.py | 薄入口，按阶段仅公布实际已实现命令 |
| README.md、examples/ | 实际运行说明与配置示例 |

包内`__init__.py`不导入模型／训练。数组接口均显式height×width，RGB为H×W×3；规范输入uint8，float计算为float32。保存NPZ禁止object数组，读取使用allow_pickle=False。

### 第1阶段：CPU资源、输入与类别协议〔准备与核验完成；背景准入阻碍〕

1. 核项目要求、已确认设计、旧geometry／render／cli源码hash，确认独立包／结果根无未知同名产物；不运行旧入口。
2. 核现有CPU解释器、依赖版本、Tk可用性、RAM／磁盘。允许正常依赖初始化，禁止Torch／模型包；Tk仅核导入与Tcl版本，暂不开窗口。不可用记录界面条件未满足，不安装或换栈。
3. 仅查既有公开来源清单和角色元信息，提出两张开发背景清单，按已有清单原序取满足来源／角色条件的前两张，不按外观或分数挑选。排除冻结S_bg／Q及评价角色与已知RGB重复；本阶段不打开图片或GT。来源不足时记录待用户提供合法背景，不扩大扫描或下载。可另准备人工平坦背景配置用于功能核验，明确非真实样本。
4. 创建protocol.py、inputs.py及独立准备／核验薄CLI，冻结两类、8位PNG／JPEG准入、EXIF转向、原生坐标与拒绝规则。透明（含带透明信息的PNG）、16位、未知模式拒绝；灰度转RGB明确记录，不能静默缩放或丢alpha。
5. 冻结请求schema：class_id、shape、polarity、center_xy／路径、尺寸／角度、amplitude、edge_width_px、variation、batch_size、base_seed；首版默认幅度0.04、0<a≤0.25、variation∈[0,1]、每批6候选。缺值或非有限数报错，设置不能暗改。
6. 仅CPU元信息／虚构坐标与标量核验，估算原生数组峰值并确定运行门槛。建议按实测峰值预算留余量，而非沿用GPU训练门槛。实际RAM不足停止，不自动缩图。

完成：独立输入协议、资源／背景元信息清单及简短准备说明；只提供实际实现的准备／核验命令。背景未准入则不得进入公开图生成。没有RGB解码、候选生成或界面通过结论。

### 第2阶段：原生几何、渲染、标签与脚本〔未执行〕

1. 核第1阶段完整准备及资源，仅解码已准入两张背景，另用明确标识的人工背景处理饱和等功能边界。保持原文件，EXIF后规范RGB另存，不读取范围外图像。
2. 实现geometry.py：椭圆、不规则块外包椭圆、直线及预设折线；坐标／宽度按像素中心定义。使用旧公式思路时注明来源，不加载旧vendor或数据模块。越界、退化、类别与形状不符报错，不移动／裁剪救请求。
3. 实现render.py：使用ROI内距离渐变建立alpha_base；variation=0时确定性，variation>0时由PCG64生成低频随机场，仅调制ROI内轮廓／内部响应。不同seed不改变M_roi，随机场归一化和零方差处理显式定义，参数与实现写入身份。不规则块随机轮廓限制在固定允许椭圆内。
4. 渐变宽度控制alpha_base的过渡距离，受小区域内切半径限制时明确报告，不能默称精确达到请求值。强度上界固定，I=clip(B+s*a*alpha,0,1)，float32计算，alpha∈[0,1]且ROI外为0。亮暗是编码RGB编辑，不标nit或严重度。
5. 实现labels.py：D=max通道|I-B|；M_changed=D>0；M_eff=D>float32(1/255)；PNG用rint(255I)转uint8，M_png为相对规范背景码值差>0。分别导出mask和class_id图，不将旧PNG>1规则混入新版。
6. 实现batch.py与CLI，配置固定后用PCG64(base_seed)预先产生6个候选seed并保存顺序，各候选独立使用自己的PCG64。全部候选生成一次，不自动重抽。导出background/generated无损PNG、ROI／标签图、float数组NPZ、参数／来源／实现元信息与全部候选manifest。成功批次写complete标记，部分事务保留停止。
7. 状态至少区分正常候选、无实际变化、PNG不可见、饱和退化；任何裁剪报告warn和实际形态量，不能单凭非空称控制通过。M_eff空但PNG不空如实标阈值现象。单实例不是连通域数，不补mask。

完成：两类×亮暗的脚本候选包及实际运行说明；记录耗时／资源，明示失败和实际变化。未做专家真实性验收。

### 第3阶段：固定条件抽卡与控制能力核验〔未执行〕
