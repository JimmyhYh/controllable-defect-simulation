# 受控探针主线：研究问题

日期：2026年10月26日。状态：**仅研究问题提案，未开发、未执行、未修改任何既有计划状态或冻结产物。** 私人设备、公开资源、个人学习与非商业研究；公司内部材料保持隔离。

---

## 一、问题从哪来

此前四个生成方向（参数化模拟 + DRAEM 生成对照、真实参考驱动、KSDD2 少样本合成、预训练单头配对）在真实留出上的效应分别为 +1.7513（样本 SD 3.4008）与 +0.7771（配对 SD 1.2755）个百分点，两轮 t 统计量均小于 1.1（df=2），方向不一致。同一批模型在训练同池上可达 99.0%—99.9%，换到真实留出即降至 35.7%—45.4%。

这组对照指向一个此前从未被直接测量的前提：**这些缺陷相对于目标检测器的工作点，到底有多少可探测裕量。** 如果裕量本身很小，则任何"多样性补充"的效应都会被信噪比压制，此前观测不到的增益不需要新实验就能解释；如果裕量充足，则零增益只能归因于训练侧的分布不匹配与监督量变化，仍有继续空间。

此前所有训练对照都在没有回答这个前提的情况下进行。

## 二、研究问题

### 2.1 主问题

> **在真实显示屏正常背景上，以残差可核验的参数化扰动作为唯一刺激，固定检测器的整图检出响应如何随扰动强度与面积变化；真实显示屏缺陷在该检测器工作点上的响应裕量是多少；该裕量能否解释此前合成补充实验中观测不到的定位增益？**

### 2.2 三个子问题

| 编号 | 子问题 | 输出 |
| --- | --- | --- |
| SQ1 | 检出响应随扰动强度是否单调、可复现，能否定出 50% 检出点 | 强度—检出率曲线与 50% 检出档位 |
| SQ2 | 该检出点在面积、形态与背景变化下是否稳定 | 检出点随面积/形态/背景的变化幅度 |
| SQ3 | 真实缺陷的响应落在该曲线的哪个位置 | 真实异常响应相对各自 τ 的倍数分布 |

### 2.3 直觉版

**这批缺陷到底有多容易被检出，以及合成扰动要多大才能被检出。** 前者决定合成还有没有用，后者决定合成该生成多大。

## 三、研究方法

### 3.1 研究类型与定位

本研究属于**测量与标定研究**，不是算法改进研究。它不提出新检测器，不比较 SOTA，不追求指标提升；它建立一把尺子，用来回答"给定检测器在给定缺陷上能做到什么"。

由此评价标准不同：算法研究看数字大小与排名，测量研究看**可重复性、偏倚可控性与不确定度可量化**。三条自检是：同身份重跑结论一致；已知真值的刺激必须产生可预期的响应；每个结论都带样本量与不确定度说明。

方法可概括为：**以受控合成缺陷为刺激源的检出概率标定，以 SEMU 归一化人眼参照。**

**可探测性**在本研究中指"该检测器在冻结的阈值工作点下把该刺激判为异常"，不是物理成像信噪比意义上的可探测性。两者相关但不等同；本研究只对前者作操作定义。

### 3.2 刺激层

**刺激**由参数化渲染器在真实正常背景上合成，参数（位置、面积、形态、幅度）全部预先记录。

**真值**取实际 float 残差 `D = max_RGB|I_syn − I_bg|` 与有效域，不以请求 ROI 或可视化掩码代替。操作掩码 M 只是操作范围，**不是可见缺陷真值**。

**强制核验**：掩码外残差必须为 0；强度档位间的能量比必须等于幅度比的平方；重算误差只允许 float32 舍入量级。任一项不成立则该批刺激作废，不得进入推理。

### 3.3 响应层

每个刺激记录三个互不合并的读数：

| 读数 | 定义 | 回答 |
| --- | --- | --- |
| 整图判定 | 整图分数 > 检测器冻结 τ 即 hit | 判不判异常 |
| 定位命中 | 像素峰值是否落在操作区 M 内 | 定位准不准 |
| 信号强度 | 分数相对配对正常对照的变化量 | 信号有多强 |

三者分别对应检出、定位、幅度；合并成单一指标会重现全局 AP 的混杂问题。

**响应裕量**定义为 `score/τ`，取值为 1 即刚好落在决策边界上；它只作描述性读数，判据使用 SEMU 刻度（见 5.2）。

### 3.4 统计层

**主方法采用 hit/miss 概率检出曲线（POD）**，按 MIL-HDBK-1823A：以"整图判异常"为二项响应，以刺激档位（或其对数）为自变量拟合广义线性模型，输出 POD 曲线与 **a90/95**（90% 检出、95% 置信对应的档位）。

**横轴提供两套刻度，并行报告：**

| 刻度 | 定义 | 用途 |
| --- | --- | --- |
| 物理刻度 | 幅度、面积像素数、形态类型 | 工程沟通；可与其他系统换算 |
| SEMU 刻度 | `Cx = (Lo−Lb)/Lb × 100`（%）；`C_jnd = 1.97/S^0.33 + 0.72`（%，S 单位 mm²）；`SEMU = abs(Cx) / C_jnd` | 与人眼阈值对齐；跨形态、跨面积可比 |

SEMU 刻度的价值在归一化：不同面积、不同形态的刺激在物理刻度上不可比，在 SEMU 刻度上可放进同一张曲线，且 SEMU = 1 有明确语义（人眼刚可察觉）。

**判据使用 SEMU 刻度**（见 5.2）；τ 倍数保留为描述性读数。两者并行报告，但只有 SEMU 参与终止/保留判定。

### 3.5 设计层

- **被试内配对**：同一背景、同一位置、同一形态，只改档位；不重抽背景、不换素材。
- **独立单元是背景，不是刺激数。** 20 个背景 × 8 档 = 160 个刺激，但独立单元只有 20 个；置信区间按背景聚类计算，不按刺激数计算。这是本设计的硬性限制，也是阶段 2 要求 50—100 个背景的原因。
- **样本量与精度**：POD 拟合的经验起点为 40 个以上独立试样。50—100 个背景可支持曲线拟合，但 a90/95 的置信下界会明显宽于标准研究；报告须给出实际区间宽度，不以点估计代替。
- **对照**：每背景必含"未加刺激的原始图"作为基线，用于扣除背景本身的响应。

### 3.6 质量控制

- 每个刺激只推理一次，完整同身份缓存只读复用；部分或未知事务保留停止，不补推。
- 档位、背景清单、形态比例、检测器与 τ 在运行前冻结；结果不利时不改档位、不换背景、不选中间权重。
- 刺激身份与推理身份绑定；任一 hash 不符即作废该批。

### 3.7 推断边界

所得结论是**能力标定**，不是性能提升，也不是准确率。它只覆盖：该域、该批背景、该检测器版本、该组形态参数。跨产品、跨批次、跨成像条件不外推。

## 四、设计与固定条件

| 项 | 固定值 |
| --- | --- |
| 域 | 主问题结论域：AnoLCD display（真实显示屏），正常背景取自 `train/good` 2400 张的固定子集；阶段 1 另用 MVTec leather 作方法预检，不作主问题结论 |
| 检测器 | 主：PatchCore（AnoLCD 上已有库与配置，不训练）；对照：DRAEM-A/B（已有权重） |
| 阈值 | 各检测器原冻结 τ，不重新校准、不搜索 |
| 尺度约定 | **k = 0.10 mm/px**（约定值，非物理标定）：1024 px = 102.4 mm 视场，1 px² = 0.01 mm²。另做 k ∈ {0.05, 0.20} 敏感性带 |
| 参数化来源 | 形态参数（椭圆半轴、线长宽、角度）沿用已冻结的模拟协议，不从评价集拟合 |
| 强度水平 | **8 个水平 = 1 个无刺激基线 + 7 档 SEMU 几何级数（0.25／0.5／1／2／4／8／16，2 倍递增）**；每档幅度由 `A = SEMU × C_jnd/100 × Lb` 反推，不按幅度等间隔 |
| 面积档位 | 4 档（由半轴/线长缩放实现，形态不变）；阶段 1 不引入，阶段 2 引入 |
| 形态 | Mura 式、线状（亮/暗各半） |
| 配对 | 同一背景、同一位置、同一形态，只改档位；不重抽背景、不换素材 |
| 重复 | 每档每背景一次；同身份完整缓存只读复用，不重复推理 |
| 真实参考 | 以同一检测器在同一域的真实异常计算 SEMU 分布，仅作描述 |

**为什么按 SEMU 布档而不是按幅度等间隔（k = 0.10 下的实测换算）：**

| 形态参数 | 像素数 | S (mm²) | C_jnd | 冻结幅度 0.04 对应 SEMU |
| --- | ---: | ---: | ---: | ---: |
| 椭圆 半轴 8×8 | 201 | 2.01 | 2.28% | 3.50 |
| 椭圆 半轴 24×24 | 1810 | 18.10 | 1.48% | 5.41 |
| 线 24×2 | 48 | 0.48 | 3.23% | 2.48 |
| 线 96×6 | 576 | 5.76 | 1.83% | 4.38 |

取 Lb = 0.50，冻结幅度 0.04 对应 Cx = 8%，落成 SEMU 2.48—5.41——**全部高于人眼阈值，属"明显可见"**。若沿用这一幅度做探针，曲线会全程检出，测不到任何边界。这与既有 `synthetic_probes` 只在 λ = 0.5／0.1 两档看到 20/20 与 18/20 的现象一致：不是探针无效，是刺激远强于阈值。

因此强度必须按 SEMU 反推：覆盖 SEMU 0.25—16 时，各形态所需幅度约跨 32 倍（椭圆 24×24 约 0.0018—0.118；线 24×2 约 0.0040—0.258）。**这意味着探针档位不能沿用冻结协议的单一幅度值，属独立新协议。**

档位上下限的附加约束：幅度须满足 `0 ≤ Lb ± A ≤ 1`；若某形态在最高档越界，该档跳过并在报告中注明，不用调低背景亮度或改 Lb 的方式绕过。

**档位换算示例（k = 0.10，Lb = 0.50；A 为单边幅度，实际需按每个背景的 Lb 重算）**

| SEMU 档 | 椭圆 24×24 | 椭圆 8×8 | 线 96×6 | 线 24×2 |
| ---: | ---: | ---: | ---: | ---: |
| 0.25 | 0.0018 | 0.0029 | 0.0023 | 0.0040 |
| 0.5 | 0.0037 | 0.0057 | 0.0046 | 0.0081 |
| 1 | 0.0074 | 0.0114 | 0.0091 | 0.0161 |
| 2 | 0.0148 | 0.0228 | 0.0183 | 0.0323 |
| 4 | 0.0296 | 0.0457 | 0.0365 | 0.0646 |
| 8 | 0.0591 | 0.0914 | 0.0730 | 0.1292 |
| 16 | 0.1182 | 0.1828 | 0.1460 | 0.2584 |

`A = SEMU × C_jnd/100 × Lb`，故 A 与 Lb 成正比；Lb 不同的背景按其实际值重算，不得统一套用上表。最高档在 Lb = 0.50 时仍满足 0 ≤ Lb ± A ≤ 1（最紧的是线 24×2，A = 0.258，Lo 落在 0.242—0.758）。

**不训练、不重校准、不改任何既有权重与阈值。**

## 五、判据（须在运行前冻结）

### 5.1 曲线是否成立（拟合前置条件）

- **通过**：7 个 SEMU 档（基线不计入）中检出率单调不减，且至少有一档从 ≤20% 跨到 ≥80%。
- **失败**：检出率无单调趋势，或全程高/全程低（含基线本身已判异常的背景占比过高）。若失败，判为"探针在该域对该检测器无信号"，生成主线收束，不进入阶段 2。
- 曲线拟合与判据均使用 SEMU 刻度；物理刻度（幅度、面积像素）同时报告。

### 5.2 用同一把 SEMU 尺子比较任务难度与检测器能力

**两个量，同一刻度：**

| 量 | 定义 | 数据来源 |
| --- | --- | --- |
| 任务难度 | 真实缺陷的 SEMU 分布（中位数与四分位） | 真实异常图的 GT 面积与背景统计 |
| 检测器能力 | 探针曲线的 SEMU_50（50% 检出点）与 a90/95（90% 检出、95% 置信） | 本主线的刺激与响应 |

**判读规则（三条；比较边界由数据算出，不设人工阈值）：**

| 条件 | 判读 |
| --- | --- |
| 真实缺陷 SEMU 中位数 < SEMU_50 | 过半真实缺陷落在检测器 50% 检出能力之下；此前零增益可由可探测性边界解释，合成增强路线终止 |
| 真实缺陷 SEMU 中位数 > a90/95 对应 SEMU | 真实缺陷整体位于可靠检出区内；零增益应归因于分布不匹配与监督量变化，探针扩展到训练侧对照 |
| 介于两者之间 | 过渡区：报连续值，不做二元结论，保留为待判 |

**描述性判读（不作分流，且须在上述两项风险解决后成立）**：SEMU_50 ≤ 1 表示检测器不弱于人眼阈值；> 1 时报出相对人眼的倍数，即 SEMU_50 本身。此条仅用于沟通，不参与终止/保留决定。

**为什么这样定**：原先的 2τ 与 5τ 为人工设定、无依据。SEMU_50 与 a90/95 均由数据拟合得出，且真实缺陷与合成刺激在同一把尺子上测量，比较本身不需要额外阈值。SEMU = 1（人眼刚可察觉）来自 SEMI D31-1102，是本判据唯一引用的外部常数。

**判据对实现口径的鲁棒性**：三条判读规则只做"真实侧 vs 刺激侧"的相对比较。只要两侧使用同一套 SEMU 口径，S 单位、换算常数 k 或线性化选择带来的系统偏差在两边同时出现，比值关系不变，判读仍然成立。受这些口径选择影响的只有"与 SEMU = 1 的绝对对标"，即描述性判读那一行。这是本判据选相对量而非绝对量的主要理由。

**SEMU 计算口径（已按标准原文核实）**

依据 SEMI D31-1102 附录 1（SEMI Draft Document 4913A 转载原文）与 T/SLDA 017-2024：

- `C_jnd = 1.97/S^0.33 + 0.72`，**单位 %**；**S 为 Mura 面积，单位 mm²**
- `SEMU = |Cx| / C_jnd`，Cx 为 Mura 平均对比度，**单位 %（相对背景 100%）**
- `Cx = (Lo − Lb)/Lb × 100`，Lo 为缺陷区平均亮度，Lb 为背景平均亮度
- 标准原始实验条件（用于界定外推范围）：19.0 英寸 1240×768 TFT/LCD，背景亮度 50 cd/m²，观察距离 0.5／1／2 m，圆形 Mura 直径 2／5／10／25／50／100 mm，66 名受试者（20 专家 + 46 新手），JND 由受试者调至"刚好不能察觉"确定

**三项必须固定、否则数值直接错的实现细节：**

1. **单位是百分比，不是小数。** Cx 与 C_jnd 都以 % 表示。若沿用无量纲相对对比度，SEMU 会小 100 倍。
2. **S 是 mm²，不是像素数。** 已约定 **k = 0.10 mm/px**（1024 px = 102.4 mm，1 px² = 0.01 mm²），敏感性带取 k ∈ {0.05, 0.20}。误用像素数会使 C_jnd 偏小、SEMU 偏大：k = 0.10 时实测偏小 1.53 倍（4086 px）与 1.92 倍（525 px）。由于 `C_jnd ∝ (N_px·k²)^−0.33` 且受 +0.72 常数缓冲，k 从 0.05 到 0.20（4 倍范围）时 C_jnd 只变 1.50—1.75 倍，故尺度不确定性对判据影响有限。
3. **亮度必须线性化。** 标准以亮度为基础，项目输入为编码 sRGB。须做 sRGB→线性转换后取相对亮度 `Y = 0.2126R + 0.7152G + 0.0722B`；AnoLCD 中 750 张为 L 模式灰度图，可直接作亮度使用。不做线性化会使 Cx 系统性偏移。

**量级校验（k = 0.10 mm/px，用于确认实现未错位）：**

| 情形 | 阳性像素 | S (mm²) | Cx | C_jnd | SEMU |
| --- | ---: | ---: | ---: | ---: | ---: |
| 真实缺陷、中等对比度 | 4086 | 40.9 | 20% | 1.30% | 15.4 |
| 真实缺陷、低对比度 Mura | 4086 | 40.9 | 2% | 1.30% | 1.54 |
| 合成斑（KSDD2 配对实验实测均值） | 525 | 5.2 | 10% | 1.86% | 5.38 |

第二行值得注意：低对比度 Mura（Cx ≈ 2%）的 SEMU 落在 1.5 左右，恰在人眼刚可察觉边缘。这与"Mura 是低对比度、最难检测"的行业共识自洽，说明公式量级正确；若实现在此例给出 SEMU 上百或小于 0.1，即为单位或比例错误。该表为量级校验用，不是任何真实测量的结果。

**绝对对标的成立条件**：SEMU = 1 的语义成立于上述标准实验条件（50 cd/m²、0.5—2 m 观察、2—100 mm 尺度）。本项目为局部裁剪图、无观察距离与物理尺度标定，故与 SEMU = 1 的对标只在"约定尺度接近该范围"时成立，报告中须显式声明。相对比较（真实侧 vs 刺激侧）不受此限。

**旁证**：T/SLDA 017-2024 采用同一公式的逐像素形式（`C_pi`、`C_jnd_i`、`MU_i`），并给出两条可直接沿用的操作规则——像素对比度 `C_pi > 1` 才构成 Mura 候选；宽度不大于 0.30 mm 的区域不判为 Mura。后者换算到 k = 0.10 即 3 px。冻结协议线宽范围为 2—6 px，其中 2—3 px 落在该下限以下；探针仍应生成这类刺激（测检测器极限正是目的），但须在报告中标注"低于行业 Mura 判定下限"，其 SEMU 不得用作 Mura 可见度结论。

**真实缺陷 SEMU 的使用边界**：只用其 GT 与背景统计做任务难度描述，不用于选择检测器、阈值或权重。这些图像在历史研究中已被观察，故该量是描述性的，不构成新的性能评价。

### 5.3 可复现性

同身份重跑，SEMU_50 的变化不得超过一档对应的 SEMU 间隔；超出则报告为不稳定，不发表曲线结论。

### 5.4 不因结果修改的项目

档位、背景清单、形态比例、检测器与 τ、SEMU 公式参数、换算常数 k = 0.10 mm/px 及其敏感性带、线性化方案、Lb 取法与保护区半径、真实缺陷 GT 范围，全部在运行前冻结。结果不利时保留原样，不改档位、不换背景、不改保护区或尺度重取。

## 六、能回答与不能回答

**能回答**：该检测器在此域的最小可检强度与最小可检面积；响应在形态与背景上的稳定程度；真实缺陷的裕量位置；以及"合成补充为何观测不到增益"是否可由裕量不足解释。

**不能回答**：真实产线准确率；合成增强是否提升检测（本问题不训练，无"提升"这个量）；未建模形态的可探测性；生成外观逼真度；跨批次与跨产品泛化。

- 5.3 可复现性：阶段 2 至少抽 1 档同身份重跑。

## 九、可借鉴的文献与标准

本主线的方法论不是新发明，三套成熟体系可直接搬用；项目真正缺的只是把三者接到一起。

### 9.1 检出概率曲线：NDT 的 POD 体系

| 项 | 内容 |
| --- | --- |
| 标准 | MIL-HDBK-1823A（2009）《Nondestructive Evaluation System Reliability Assessment》；ASTM E3023-21 |
| 方法 | hit/miss 二项模型拟合（广义线性模型 / log-odds）或 â vs a 信号响应回归 |
| 关键量 | **a90/95**——90% 检出率、95% 置信度对应的缺陷尺寸；这是行业公认的"可靠检出下限" |
| 已迁移到深度学习 | 航发焊缝 X 射线检测中有工作把 POD 指标用于评价分割网络，并明确指出 IoU/AP 这类指标"不把目标尺寸与检出率联系起来"，因此无法回答可探测性 |
| 本项目实现 | `statsmodels` 的 Binomial GLM + bootstrap 置信下界，无需专用商业软件 |

这条体系直接提供本项目缺的统计框架：全局像素 AP 把尺寸与检出率混在一起，因此无论合成增强做了什么，AP 都只能给出一个混杂数字；POD 曲线把它们分开。

### 9.2 人眼阈值：显示屏的 SEMU / JND 体系

| 项 | 内容 |
| --- | --- |
| 标准 | SEMI D31-1102（2002）《Definition of measurement index (SEMU) for luminance Mura in FPD image quality inspection》；T/SLDA 017-2024《Mini/Micro LED 显示屏 Mura 缺陷评价方法》；ISO 13406-2 缺陷分级 |
| 核心公式 | `C_jnd = 1.97/S^0.33 + 0.72`（%，S 单位 **mm²**）；`SEMU = abs(Cx) / C_jnd`，Cx 为 Mura 平均对比度（%，相对背景 100%）；单位已按标准附录原文核实 |
| 原始实验条件 | 19.0 英寸 1240×768 TFT/LCD，背景 50 cd/m²，观察距离 0.5／1／2 m，圆形 Mura 直径 2—100 mm，66 名受试者 |
| 语义 | SEMU ≥ 1 表示人眼可察觉；面积越大，可察觉所需对比度越低（与 S^-0.33 成反比） |
| 原文出处 | SEMI Draft Document 4913A 所转载的 D31 附录 1（A1-1、A1-2 公式定义）与 Related Information R1（实验条件）；T/SLDA 017-2024 正文 5.3—5.7 条（逐像素形式与 0.30 mm 规则）。正式引用前应取得标准原文核对编号与版本 |
| 更精细模型 | NASA 的 Spatial Standard Observer（Watson）：test/reference 差分 → CSF → aperture → 非线性 pooling 得 JND 图；商业实现在 Radiant Vision 的 ProMetric / TrueMURA。**本次检索未见明确的开源实现**，按公开文献可自行实现，但成本高于 SEMU |
| 本项目实现 | SEMU 三行公式，纯 NumPy；不需要 SSO |

这一条给了本项目从未有过的参照系：**检测器要多大对比度才能检出，相当于人眼的几倍。** 这句话可以直接与产线、与行业标准对话，而 AP 做不到。

### 9.3 合成缺陷的正确形态：NDT 的 virtual flaw

NDT 领域对"用合成缺陷做可靠性评价"有成熟范式，叫 **virtual flaw**：从真实缺陷中提取信号、叠加到真实背景上，而不是用纯参数化模型生成。公开研究表明虚拟缺陷优于纯模拟缺陷，且纯模拟缺陷单独不足以泛化。

这正好解释了本项目的四轮结果：参数化渲染器属于"纯模拟"，跨域即失效；`reference_generation` 想做的属于 virtual flaw，方向正确但卡在同域素材上。**文献结论与本项目实测一致，不是本项目执行不力。**

### 9.4 评价口径的最新批评

2026 年 8 月的一篇工作（arXiv 2608.15090）明确指出 AUROC 与掩膜重叠都不能给出选定阈值下的误报率，并给出分布无关的容差阈值与样本量要求：150 张校准正常图只能支持 FPR ≥ 1.98% 的 95% 置信声明，1% 目标需至少 299 张。这与本项目"Q200 校准、同池 FP 固定为 10/200"的处境直接相关。

### 9.5 结论：不需从头

| 环节 | 状态 |
| --- | --- |
| 参数化渲染器与残差/有效域定义 | 已有（`synthesis.py`，含残差核验链） |
| 真实缺陷片段混合（virtual flaw） | 未实现，且缺同域素材，属独立分支 |
| 真实正常背景 | 已有（AnoLCD `train/good` 2400 张） |
| 检测器与冻结阈值 | 已有（PatchCore、DRAEM-A/B） |
| 检出曲线统计框架 | 需新写，但只是 statsmodels GLM，约百行 |
| 人眼阈值归一化 | 需新写，SEMU 为三行公式 |
| 刺激档位矩阵 | 需新写，是本研究的主体工作量 |
| 判据 | 已采用 SEMU 刻度 + a90/95（见 5.2），取代原无依据的 τ 倍数分流线 |

**约七成资产已有，需要新写的是档位矩阵、曲线拟合与判据三块，不是一套新方法。**

## 十、当前状态

已完成：研究问题、研究方法（七小节）、判据（SEMU 双量比较 + a90/95）、展开路线、文献与标准依据，以及 SEMU 单位核实。

**2026-10-26 核实结果**：SEMI D31-1102 附录 1 原文确认 `C_jnd = 1.97/S^0.33 + 0.72` 的单位为 **%**，S 的单位为 **mm²**；`SEMU = |Cx|/C_jnd` 中 Cx 亦为 **%**（相对背景 100%）。T/SLDA 017-2024 采用同一公式的逐像素形式，并给出 `C_pi > 1` 与"宽度 ≤ 0.30 mm 不判 Mura"两条操作规则。原先担心的"S 按像素数代入"确认为错误用法：k = 0.10 时会使 C_jnd 偏小 1.53—1.92 倍、SEMU 同比偏大，已写入禁止项。

仍未完成：代码、刺激生成、推理、任何新图像读取。**尺度已约定 k = 0.10 mm/px（1024 px = 102.4 mm，1 px² = 0.01 mm²），敏感性带取 k ∈ {0.05, 0.20}**，不再是未知量。

**由 k 换算出的一个关键设计结论**：取 Lb = 0.50 时，冻结协议的单一幅度 0.04 对应 SEMU 2.48—5.41，全部高于人眼阈值。若沿用该幅度，探针曲线会全程检出、测不到边界——这与既有 `synthetic_probes` 只看到 20/20 与 18/20 的现象一致。故强度水平改为 1 个无刺激基线 + 7 档 SEMU 几何级数（0.25—16），每档幅度由 SEMU 反推；探针档位属独立新协议，不沿用冻结协议的单一幅度。
