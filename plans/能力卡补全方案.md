## 二、任务 1：POD 标准统计

### 2.1 横轴必须用实测 SEMU，不是名义档位

已核实的名义—实测偏差（1107 个刺激）：

| 指标 | 值 |
| --- | --- |
| 相对偏差中位数 | +0.7% |
| \|偏差\| 中位数 | 3.7% |
| \|偏差\| p90 | **27.4%** |
| \|偏差\| 最大 | **153.9%** |
| 落在 ±5% 内的比例 | 62.4% |

**结论：只有六成刺激的实测 SEMU 落在目标 ±5% 内**，最大偏离超过一倍。若按 target 分档拟合，会把实际强度差很多个刺激混进同一档；用 `SEMU_actual` 则每个观测携带自己的横轴值。

这也正好符合 MIL-HDBK-1823A 的 hit/miss 做法：观测单位是单次试验，不是分档后的比例。

### 2.2 模型

单变量 probit，横轴取自然对数：

```
P(hit | x) = Φ(β0 + β1 · ln x)
a_p        = exp( (Φ⁻¹(p) − β0) / β1 )
```

输出：

| 量 | 含义 |
| --- | --- |
| `a50` | 50% 检出点 |
| `a90` | 90% 检出点 |
| `a90_95` | a90 的 95% 单侧下界（bootstrap 5% 分位） |
| `beta0 / beta1` | 拟合系数，β1 必须为正 |
| `n / n_background` | 观测数与独立单元数 |

**参考类目用的是 a90/95**（MIL-HDBK-1823A / ASTM E3023），故必须同时报 a90 与 a90/95，不得只报 a90 当能力上限。

### 2.3 为什么不装 statsmodels

`.venv` 是本项目冻结的 CPU 指标环境（NumPy 1.26.4 / SciPy 1.16.2 / sklearn 1.7.2），新增依赖会改变环境快照。probit 只有两个参数，自实现 MLE（Newton 迭代）足够，且代码可审计。

**但自实现必须交叉验证**，否则等于自说自话。用两条独立路径：

1. **与现有线性插值 SEMU_50 对照**：两者口径不同（插值用 target 分档，MLE 用 actual 单点），但若差异 < 0.5 SEMU 单位，说明量级一致。
2. **与 logit link 对照**：同一数据换 logit 连接函数，a50 应接近（probit 与 logit 在中等概率处几乎重合）。

两条都通过才采用；任一条明显不一致，则报告差异并暂停，不直接用。

### 2.4 置信区间：按背景聚类 bootstrap

同一背景上叠加的 8 个档位不独立，直接对 1107 个观测重采样会低估区间宽度。故按 `background_index` 整组重采样，2000 次。

独立单元是背景（47 个），不是观测数（1107）。这一点必须在报告里写明，否则区间会被误读为"样本量 1107"。

### 2.5 验收

| 检查 | 通过条件 |
| --- | --- |
| 收敛 | 4 个形态的 β1 > 0 且迭代收敛 |
| 与插值一致 | \|a50_probit − a50_interp\| < 0.5（SEMU 单位） |
| 与 logit 一致 | \|a50_probit − a50_logit\| < 0.3 |
| bootstrap 有效 | 有效重采样数 > 95% |

**任一形态拟合失败（β1 ≤ 0 或发散），如实报告"该形态无单调响应、不给 a50"，不强行出数。**

## 三、任务 2：DRAEM-A/B 能力卡

### 3.1 输入（已核实全部就绪）

| 资源 | 路径 | 状态 |
| --- | --- | --- |
| 刺激缓存 | `results/pod_probe/anolcd_stage2_v1/stimuli/*.npz` | 1167 个，256×256×3 float32 |
| DRAEM-A 权重 | `models/weak_localization/draem_A_20261020/` | 在 |
| DRAEM-B 权重 | `models/weak_localization/draem_B_20261020/` | 在 |
| 冻结 τ | A `0.999303674697876` / B `0.9995600938796997` | 在 |

### 3.2 口径（三条硬约束）

1. **必须采基线误报**：60 个未加刺激的正常背景要单独判一次，否则只有敏感度没有特异度。
2. **跨检测器不比 `score/τ`**：DRAEM 的 τ 在 softmax 概率域，`score/τ` 上限约 1.0007，与 PatchCore 的 3.29 不可比。跨模型只能比**检出率**与 **a50/a90**。
3. **不重新校准 τ**：沿用冻结值，与 PatchCore 同一规则（V479 q0.95）。

### 3.3 预期与处理

DRAEM-A/B 在真实数据上 AUROC 为 49.95 / 50.37，故很可能出现**全档 0% 检出**。

若如此，处理方式不是"再找原因"，而是按任务 3 的准入门槛判定：**该检测器在本刺激集上无可测响应，能力卡不填 a50，判据不适用于它。** 这本身是有效结论——它说明该模型不是"弱"，是"从不出警"。

### 3.4 验收

- 两个模型各 1167 次推理，输出逐图分数
- 基线误报率（x / 60）记录在案
- 逐档检出率表与 PatchCore 同格式
- 若全档 0 检出，写明"无可测响应"，不给 a50

## 四、任务 3：判据逻辑修补

### 4.1 要修什么

现有 5.2 的三分支判据从"真实缺陷 SEMU 与检测器 a50/a90 的关系"推出"补样本是否有用"。这个推论有一个未写出的前提：

> **该检测器在这些刺激上确实产生了可测的响应。**

若检测器全档不响应（曲线贴 0），它"不在检出区内"并不代表缺陷难，而是代表检测器没学会。此时判"可探测性边界解释零增益"是错的。

### 4.2 修法

把 5.1（曲线是否成立）设为 5.2 的**准入门槛**，写进协议正文：

```
5.1 通过 → 才允许执行 5.2 的三分支判读
5.1 不通过 → 判"该检测器在本刺激集上无可测响应"，5.2 不适用，
            不得据此对数据侧下任何结论
```

并补一个状态值 `no_response`，与 `saturated`、`flat_zero`、`non_monotonic`、`insufficient` 并列。

### 4.3 影响范围

只影响协议文本与报告的判读措辞，**不影响任何已封存数字**。已有的 A/B/C 判读在 PatchCore 上仍然成立（它的 5.1 是通的）。
