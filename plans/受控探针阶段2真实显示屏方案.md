## 一、阶段 1 暴露的两件事，决定了阶段 2 的形态

1. **可表示下限是硬约束**：8-bit 编码下残差必须超过 1/255，故小面积才能把 SEMU 压到 1 附近。
2. **太细的形态不可用**：`line_short`（32 px）在 SEMU 16 时检出 0.70，但定位命中仅 0.45，说明检出多来自整图分数而非缺陷位置，已降级为不作证据。

因此阶段 2 不照搬阶段 1 的四个形态。**先用真实缺陷的 SEMU 分布定形态参数**，再布探针。

---

## 二、一个关键事实（决定实现路径）

核查 `results/weak_localization/frozen_config.json` 与 `first_round_config.json`：AnoLCD 的 PatchCore 输入为 **whole RGB bilinear 256**——整图 1024 被双线性缩到 256 后送检，输入尺寸 256，coreset 0.01，80 张正常图建库，阈值 τ = **1.8928574562072753**（479 张正常校准，同池 FP 24，FPR 5.01%）。

这意味着：

- **探针应在 256 缩图上渲染，而不是在 1024 上渲染再缩。** 后者会让刺激二次下采样、削弱对比度，且无法与"检测器实际看到的图像"对齐。
- **可以直接复用现有 AnoLCD PatchCore 与 τ，不必重建实例。** 阶段 1 因渲染器与检测器分辨率不一致才新建了 256 实例；阶段 2 恰好一致，省掉这一步。
- 结果与历史 85.8349% 的 PatchCore 评价同库、同阈值、同输入口径，可比。

尺度换算仍沿用 `k(r) = 102.4 / r`：r = 256 → **k = 0.40 mm/px，1 px² = 0.16 mm²**。

---

## 三、背景图必须排除建库与校准用图

AnoLCD `train/good` 共 2400 张，其中 80 张建库、479 张校准。探针背景若取自这些图，测到的是**模型对这些特定图的记忆**，不是对新图像的响应。

**方案**：背景取自 `test/good` 350 张（未参与建库与校准），用 PCG64 固定种子选 60 张、按路径排序。

**必须标注**：`test/good` 属于历史 Tfinal 评价集，已被旧研究观察。本阶段只用它作刺激背景，**不据此评价任何性能**；因此其证据等级仍是 L2（历史已见的留出），不构成独立未见验证。

## 四、两步执行

### 2a 真实缺陷 SEMU 统计（纯 CPU，不加载模型）

目的：得到 AnoLCD 真实缺陷的 S、Cx、SEMU 分布，用来定 2b 的形态参数，并作为 5.2 判据的"任务难度"侧。

| 项 | 内容 |
| --- | --- |
| 数据 | `display/test` 的 750 张异常图及其 `ground_truth` 二值掩码 |
| 预处理 | 1024 → 256 双线性缩放，图像与掩码同步（掩码用最近邻） |
| S | GT 阳性像素数 × 0.16 mm² |
| Lb | 同图内 GT 外扩保护区之外的亮度均值 |
| Lo | GT 内亮度均值 |
| Cx | `(Lo − Lb)/Lb × 100`（%） |
| SEMU | `Cx / (1.97/S^0.33 + 0.72)` |
| 输出 | 按缺陷类型（mura / line / spot / scrathes / cylinder）分组的 S、Cx、SEMU 分位数 |
| 成本 | 分钟级；不涉及模型 |

**注意**：保护区半径须固定；不因结果调整。GT 为作者标注，二值 0/255，须先核尺寸与取值。

**2a 已完成（2026-10-27）**，结果见[第 2a 阶段真实缺陷 SEMU 分布结果](D:/华兴源创/实验/弱缺陷Demo/results/pod_probe/anolcd_stage2_v1/第2a阶段真实缺陷SEMU分布结果.md)。要点：

- 750 张中 **510 张适用**；`cylinder` 200 张全部不适用（GT 覆盖 56%—65%，无可定义背景）。
- SEMU 中位数 **7.15**，IQR 2.32—15.25；按类型：line **1.85**、mura **8.21**、scrathes 10.71、spot 11.64。
- mura 的 S 中位数 27.7 mm²（IQR 8.6—74.4），折算椭圆半轴约 4.1 / 7.4 / 12.2 px。
- 多数缺陷对人眼明显可见；真正接近阈值的只有 line（约 10% 的 line 图 SEMU < 1）。
- 实现经两次口径修正（全图外部均值 → 环带均值 → 环带中位数 + 适用性判据），两版失败现场均保留。

### 2b 探针测量

形态参数由 2a 的分位数决定（例如取 SEMU 中位数附近与 S 中位数附近各一组），不在这里预设。其余沿用阶段 1：

| 项 | 值 |
| --- | --- |
| 背景 | test/good 固定 60 张 |
| 检测器 | 现有 AnoLCD PatchCore（不重建、不重校准） |
| 阈值 | τ = 1.8928574562072753 |
| 档位 | 8 档 SEMU：1.0 / 1.6 / 2.5 / 4 / 6.3 / 10 / 16 / 25（覆盖真实 IQR 2.3—15.2） |
| 形态 | 4 组，由 2a 实测分位定（见下） |
| 渲染 | 256×256；每组合逐背景可表示性预判 |
| 推理 | 现有库直接前向 |

**2b 的四个形态（依据 2a 实测分位，非沿用 leather 尺度）：**

| 形态 | 依据 | 256 尺度几何 |
| --- | --- | --- |
| `mura_p25` | mura 的 S p25 = 8.6 mm² | 椭圆半轴 ≈ 4 px |
| `mura_med` | mura 的 S 中位 = 27.7 mm² | 椭圆半轴 ≈ 7 px |
| `mura_p75` | mura 的 S p75 = 74.4 mm² | 椭圆半轴 ≈ 12 px |
| `line_med` | line 的 S 中位 = 74.2 mm² | 线长 ≈ 19 × 宽 4 px |

规模估算：4 形态 × 8 档 × 60 背景 ≈ 1920 渲染 + 60 基线。渲染分钟级，推理分钟级。

## 五、判据

**A. 曲线是否成立**（同阶段 1）：至少一个形态单调（容差 0.05）且至少一档从 ≤20% 跨到 ≥80%；并记录 `saturated` / `flat_zero` / `insufficient`。

**B. 与真实缺陷的比较**（主问题的核心）：把 2b 得到的 `SEMU_50` 与 `a90/95 对应 SEMU`，同 2a 的真实缺陷 SEMU 分布（中位数与四分位）比较：

| 条件 | 判读 |
| --- | --- |
| 真实 SEMU 中位数 < SEMU_50 | 过半真实缺陷落在检测器 50% 检出能力之下；此前合成补充的零增益可由可探测性边界解释 |
| 真实 SEMU 中位数 > a90/95 对应 SEMU | 真实缺陷在可靠检出区内；零增益应归因训练侧，探针扩展到训练对照 |
| 介于两者之间 | 过渡区，报连续值，不做二元结论 |

**C. 描述性**（不作分流）：`SEMU_50` 相对 1 的倍数。因未做 sRGB 线性化，只作相对比较，不与 SEMU = 1 绝对对标。

---

**2b 已完成（2026-10-27）**。核心结果：真实 mura 的 SEMU 中位 8.21，而检测器的 SEMU_90 在 mura_med 为 4.58、mura_p75 为 3.71、mura_p25 为 9.45。对最接近真实面积中位的 mura_med，**缺陷整体位于可靠检出区内**，故「合成补充无增益」在本域本检测器上不能由可探测性边界解释（判据 B），应归因训练侧。`line_med` 在最低档已 0.67，属量程不足（`below_min`）。

**该结论不能外推到 KSDD2**：本阶段是 AnoLCD + 无监督 PatchCore，而零增益来自 KSDD2 + 少样本有监督模型，域与设定均不同。

### 5.x 判据准入门槛（2026-10-27 修补）

5.2 的三分支判读隐含一个前提：**该检测器在这些刺激上确实产生了可测响应**。若检测器全档不响应（曲线贴 0 或全档饱和），"不在检出区内"并不意味着缺陷难，而是意味着检测器没学会；此时判"可探测性边界解释零增益"是错的。

故规定：

```
5.1 通过（曲线单调且有跨越） → 才允许执行 5.2 的三分支判读
5.1 不通过                  → 判 no_response，5.2 不适用，
                              不得据此对数据侧下任何结论
```

新增状态 `no_response`，与 `saturated`、`flat_zero`、`non_monotonic`、`insufficient` 并列。

**影响范围**：只影响协议文本与报告措辞，不改动任何已封存数字。PatchCore 的 5.1 已通过，其 A/B/C 判读不受影响。

### 5.z A 分支细分（2026-10-27 新增）

原 A 分支把「真实缺陷 SEMU 中位 < a50」统一读作「可探测性边界（对比度不足）解释零增益 → 补样本终止」。这个读法在 spot 上会是对的结论、错的原因：spot 的真实机理是特征图上占位不足（0.35 个位置），不是对比度不够。

故 A 细分为两支，判据依据是形态在特征图上的占位（等效直径 ÷ stride 8）：

| 子分支 | 条件 | 含义 | 对策 |
| --- | --- | --- | --- |
| **A1** | a50 > 真实中位，且占位 **≥ 1** | 特征可表达，属对比度不足 | 补样本可能有效 |
| **A2** | a50 > 真实中位，且占位 **< 1** | 面积过小导致特征不可表达 | 补样本无效，应改检测器结构（patchsize / 特征层 / 更高输入） |

**a50 不可估时的处理**：若最高档检出率仍 < 50%，说明 a50 高于数据上界，同样判为落 A（此时用最高档率作下界依据，不报 a50 点值）。

判据生效位置不变：仍以 5.1（曲线成立）为准入门槛。

### 5.y POD 口径（2026-10-27 升级）

检出点改由 Probit GLM（hit/miss，横轴取实测 SEMU）估计，报 a50 与 **a90/95**；区间按背景聚类 bootstrap。原分段线性插值结果降级为参考，仅在与 MLE 一致时引用（`mura_med` 差 0.03）。详见 `results/pod_probe/capability_v1/POD口径升级结果.md`。

## 六、能回答与不能回答

**能回答**：AnoLCD 真实缺陷的 SEMU 分布；该检测器在此域的 SEMU_50 与 a90/95；两者是否重叠；即"合成补充为何观测不到增益"是否可由可探测性边界解释。

**不能回答**：真实产线准确率；合成增强是否提升检测；跨产品泛化；Mura 的绝对可见度（因缺线性化与观察距离标定）。
