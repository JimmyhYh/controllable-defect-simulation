# 可控缺陷模拟与工业检测验证

**Controllable Defect Simulation & Industrial Inspection**

面向工业视觉中的少样本与弱缺陷问题，构建可解释的 Mura 式和线状缺陷模拟工具，支持位置、形状、大小、方向、亮暗与强度控制，并结合公开数据开展检测对照和响应测量。

## 项目亮点

- **参数化缺陷模拟**：通过几何与强度参数控制局部亮度扰动，支持块状与线状外观。
- **多层标签输出**：区分请求区域、连续扰动场、实际像素变化和有效掩码，便于检查生成结果。
- **完整评价链路**：分别报告像素定位 AP、整图 AUROC 和固定阈值下的误报／漏检，支持原生分辨率窗口推理。
- **配对实验与受控测量**：比较合成样本对少样本训练的影响，并测量固定检测器对不同几何、幅度和亮暗刺激的响应。

## 实验概览

| 实验 | 结果 |
|---|---|
| 模拟控制 | 24个预定请求全部有效，区域外像素零改动 |
| 共享模拟留出 | 480请求中460有效、20无效，保留无效原因 |
| 模拟域适配 | 主强度下G0/G1像素AP为55.1564% / 99.0349% |
| KSDD2真实数据配对 | 两轮各3对实验，像素AP平均差为+1.75 / +0.78个百分点，收益不稳定 |
| 固定PatchCore响应 | 60背景、7560刺激请求；实际非零刺激的空间联合报警率42.88% |

模拟域高分仅说明对该渲染机制的适配；真实工业实验尚未证明稳定检测收益。响应测量反映固定刺激条件下的模型行为，不能替代真实缺陷检出率。
