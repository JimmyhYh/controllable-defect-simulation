## 结果与边界

* 24个预定控制请求全部有效；共享模拟留出480请求中460有效、20无效，保留失败。
* G0/G1共享渲染器域主强度像素AP 55.1564% / 99.0349%，不是真实屏幕收益。
* 两轮各三对真实KSDD2配对训练，像素AP平均差+1.7513 / +0.7771个百分点，方向不稳定。
* 固定PatchCore D_fit：60背景、7560请求，非零刺激空间联合报警3107/7245（42.88%）；不是独立真实缺陷检出率。
* 六个统计候选拟合完成；D_hold60已准备但未评分。
* 类别＋空间标签候选工具第1阶段准备完成，有背景准入阻碍（0/2）；RGBA兼容提案待批准，渲染及界面未完成。
