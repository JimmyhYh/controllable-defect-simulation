# 真实正常背景上的受控合成与敏感度结果

2026年10月10日，第二周第3天在私人设备上完成。只使用MVTec AD leather预留正常背景P及DTD外部纹理。**这是固定PatchCore对受控合成变化的敏感度观察，没有训练检测器，不能解释为训练收益或显示屏／Mura效果。**第2天真实评价单独保存，本步骤不读取E图像、标签或衍生素材，不把合成图加入真实测试结果。

## 数据和唯一变化因素

沿用已固定R176/V49/P20，正式正常库仍为R前80张、627×1024向量。P不进入正常库或V阈值；本步骤未调用fit，也没有重新标定。正式配置SHA256 `30fde76a4638c24f85785a8ba166c9bfeb21b9f2ee70dcde2a318fe7d6219c67`，阈值 `1.5751205444335934`，严格score > threshold判异常。作者骨干初始化及评分／热图处理与第2天一致。

DTD官方split 1训练清单共1880条，先按相对路径排序，再用numpy.random.default_rng(42)的PCG64排列，取前20条；逐个对应固定P顺序，i从0开始，合成种子42000+i。训练清单与DTD的val1/test1清单已核对互斥；这里只解出需要的20张纹理和划分清单。素材路径、文件哈希、背景对应和随机设置见[evaluation.json](evaluation.json)，这是最终实验数据，不是过程表。

复用作者DRAEM `2dbf67397ab5c10a1494e5ae70ab59a25d7c35ef` 的生成机制：调用原类的randAugmenter，从10种纹理增强中无放回选3种并按抽样顺序执行；沿用原Perlin函数、掩码旋转[-90°,90°]、各轴2的0—5次幂尺度及噪声 > 0.5的硬阈值。具体定位：[data_loader.py L80–103（增强）](https://github.com/VitjanZ/DRAEM/blob/2dbf67397ab5c10a1494e5ae70ab59a25d7c35ef/data_loader.py#L80-L103)、[L107–136（Perlin及混合）](https://github.com/VitjanZ/DRAEM/blob/2dbf67397ab5c10a1494e5ae70ab59a25d7c35ef/data_loader.py#L107-L136)、[perlin.py L46起（原函数）](https://github.com/VitjanZ/DRAEM/blob/2dbf67397ab5c10a1494e5ae70ab59a25d7c35ef/perlin.py#L46)。

为每对图只生成一次增强纹理T和非空操作掩码M，背景B按第2天整图RGB双线性缩放224×224、/255。按 **Xλ = B + λ M (T − B)** 生成强组A（λ=0.5）和弱组B组（λ=0.1；与背景符号B区分）。两组固定相同的背景／纹理／掩码，只改变混合强度，不加入边界平滑或其他候选因素。结果20对全部有效，共40张合成图和20张正常对照；P17的首次掩码为空，按固定随机序列第二次得到非空掩码，其余19对首次成功，没有排除样本。每对最多10次掩码尝试。

适配处明确如下：禁用作者的背景随机旋转；替换随机beta与50%正常样本分支，保证每个非空掩码生成固定λ成对图；T在重试掩码时不重抽。原beta=U[0,0.8)，λ=1−beta约在(0.2,1]，所以λ=0.1超出作者原随机范围；本结果称为“基于DRAEM生成机制的受控适配”，不是完整DRAEM复现。原作者纹理增强包含GammaContrast，它仅是固定T生成的一部分，两组共享T，未对B或成对图额外实施Gamma增强。相关原分支见[data_loader.py L126–153](https://github.com/VitjanZ/DRAEM/blob/2dbf67397ab5c10a1494e5ae70ab59a25d7c35ef/data_loader.py#L126-L153)。

中文路径不适合cv2.imread，使用Python读字节、cv2.imdecode解码，保持作者内部BGR纹理增强顺序，增强后转换RGB。正常背景沿用PIL双线性变换，DTD纹理沿用OpenCV线性缩放。所有检测输入来自float32 RGB[0,1]数组，固定ImageNet归一化；**PNG预览仅供查看，不回读成模型输入**，没有8位量化后再推理。模型仅收到当前图像数组，背景／掩码仅在外部评价使用。

## 真实残差核对

对实际保存的浮点图计算Δ=Xλ−B。操作区平均绝对RGB变化为sum|Δ|/(3|M|)，最大值遍历M内全部通道；能量为全图全部像素通道的sum Δ²，使用float64累加。灰度代理为ΔY′=0.2126ΔR+0.7152ΔG+0.0722ΔB，在M内统计|ΔY′|；这是归一化、编码RGB的加权代理，不代表显示器线性亮度或真实色差。以下每项“均值”为20对每图对应统计的算术平均，不把面积较大的掩码赋更多权重。

| 残差量 | λ=0.5 | λ=0.1 |
|---|---:|---:|
| 操作区平均绝对RGB变化，逐图平均 | 0.13454954 | 0.02690991 |
| 操作区最大绝对RGB变化，逐图平均 | 0.35205884 | 0.07041176 |
| 操作区平均绝对灰度代理变化，逐图平均 | 0.12475486 | 0.02495097 |
| 全图残差能量，逐图平均 | 211.810714 | 8.472429 |
| 掩码外平均／最大绝对RGB变化，全部图 | 0 / 0 | 0 / 0 |

20对掩码面积1124—4921像素；实际变化像素以任一RGB通道Δ≠0定义，本次各图与其M像素数量相同，但不能据此称M为人工可见缺陷GT。弱组能量/强组能量逐对均值 `0.040000000236`，符合理论1/25；弱组残差与0.2×强组残差的全批最大绝对误差 `2.98023223877e-08`，来自float32舍入。20对保存的T/M已按同种子重新生成，逐元素完全相同；P背景归一化张量与原read_image接口完全一致。

**掩码外为0是局部混合的构造性质，不证明生成器学到了背景分布。λ减少使信号幅度与能量同时下降；检测响应变低说明该固定检测器对这些弱化纹理变化的响应，不说明生成方法更差，也不是检测算法提升。**单次、小规模、单一leather类别，仅两个强度；没有置信区间，没有真实屏幕验证，不能外推屏幕缺陷严重度或产线性能。
