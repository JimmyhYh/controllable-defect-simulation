# spot 形态探针结果：判据 A 分支首次触发

日期：2026年10月27日。执行：助手（渲染为纯 CPU、推理为 GPU），全部只做推理，无训练。
状态：**判据 A 分支首次触发，落 A2。**

---

## 一、为什么补这个形态

阶段 2b 的四个形态最小只到 `mura_p25`（S = 8.0 mm²），而真实 spot 是 **0.96 mm²**，小 8.3 倍。所以"检测器对 spot 尺度的 50% 检出点"从未被测过，判据的 A 分支（真实缺陷 SEMU 中位 < a50 → 该补样本）一直没有实例。

本实验补一个 `spot_xs` 形态：椭圆半轴 1.4 px，实测 **S = 0.800 mm²**（真实 spot 0.96，差 17%），等效直径 2.8 px。

---

## 二、执行条件

| 项 | 值 |
| --- | --- |
| 背景 | 与 2b 完全相同的 60 张 `test/good`，基线图直接复用 |
| 档位 | 8 档 SEMU 1.0—25 |
| 渲染 | 384 条刺激，**problems 0**，156 条因 8-bit 下限不可表示 |
| 样本构成 | 1.0 档 17 条、1.6 档 25 条、2.5—25 各 47 条 |
| 推理 | PatchCore，冻结库，τ = **1.8928574562072753** |
| **基线误报** | **6/60** ——与阶段 2b 完全相同，实现一致性通过 |
| 实测 S | 0.800 mm²（全 47 个背景稳定） |
| 实测 Cx | 中位 17.57%，范围 2.6—74.5% |

## 三、结果

| target SEMU | n | 检出率 |
| ---: | ---: | ---: |
| 1.0 | 17 | 0.176 |
| 1.6 | 25 | 0.200 |
| 2.5 | 47 | 0.106 |
| 4.0 | 47 | 0.234 |
| 6.3 | 47 | 0.362 |
| 10.0 | 47 | **0.426** |
| 16.0 | 47 | **0.426** |
| 25.0 | 47 | **0.426** |

**两件事同时发生：**

1. **最高档只有 42.6%，从未跨过 50%。**
2. **10、16、25 三档完全持平在 0.426**——把刺激强度再加一倍半，检出率一点不动。

这是饱和，但不是"全检出"的饱和，而是**卡在 42.6% 的天花板**。

---

## 四、判据判定：A2

| 项 | 值 |
| --- | --- |
| a50 | **不可估**（最高档 42.6% < 50%，拟合会外推到 86—85039，已弃用） |
| a50 下界 | > **26.22**（数据上界） |
| 真实 spot SEMU 中位 | **11.64** |
| 特征占位 | **0.315**（等效直径 2.8 px ÷ stride 8） |

判定过程：

```
真实 11.64 < a50（>26.22）  → 落 A 分支（缺陷落在检测器能力之下）
占位 0.315 < 1              → A2
```

> **A2：面积过小导致特征不可表达，不是对比度不足。补样本无效，应改检测器结构。**

---

## 五、这条结论的意义

**一、判据的 A 分支终于有了实例。** 此前 PatchCore 落 B、G1 落 C，"该补样本"这一支从未被触发，判据只算半验证。现在 A 分支被触发了，而且是**以 A2 而非 A1 的形式**——如果当初没做细分，这里会给出"对比度不足 → 补样本可能有效"的错误建议。

**二、两条独立路径互相印证。** 判据走的是「a50 vs 真实中位 + 特征占位」；而此前对 spot 的机理分析走的是「面积×对比度 vs 召回 + 占位 0.35」。两条路径独立，结论一致：**spot 的问题是结构性的，不是强度不足**。

**三、饱和形态本身就是证据。** SEMU 从 10 加到 25，Cx 从约 17% 加到 60%+，检出率一动不动。如果瓶颈是对比度，加对比度应当有效。"加到饱和也不动"正是"信号在进入网络前就没了"的直接表现。

---

## 六、一个必须说明的差异

本形态的 S = 0.800 mm²，真实 spot 是 0.96 mm²，**小 17%**。原因：半轴 1.4 px 在软边渲染器里，有效域比几何面积收缩更多。

这会让本形态比真实 spot **略难**，所以结论方向是保守的（如果连这个更难的都判 A2，真实 spot 更应如此）。但它不是精确配对，不能用于定量外推。

---

## 七、曲线非单调，如实记录

2.5 档（0.106）低于 1.0 档（0.176）。n = 47，差 3 条样本。这是二项抽样噪声，不是系统性回退。

按协议 5.1，曲线需"单调且有跨越"才准入 5.2。本形态**没有跨越 50%**，所以严格说 5.1 未通过——这正是判 A2 时采用「a50 下界 > 数据上界」而不是「a50 点值」的原因。
