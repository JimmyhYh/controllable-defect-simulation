# 可控Mura式与线状缺陷生成：首次试用结果

日期：2026年10月14日。按用户同意的推荐方案完成CPU生成、实际标签核验与固定检测器响应，未训练生成网络或新的DRAEM，未执行新真实评价。不是两周计划全部完成。

## 本次实际实现

指定工作坐标、位置、形状、尺寸、方向及亮暗幅度，输出模拟图、请求区域M_roi、混合权重alpha、实际有效掩码M_eff、PNG有效掩码及真实残差。支持圆、椭圆、简单多边形、直线、折线及AnoStyler轮廓适配。

固定[AnoStyler](https://github.com/yulimso/AnoStyler)提交19a41c9965a9ce3f2057890850e50efe0bcb58d6的MIT形状源码和许可；两个blob请求实际复用msp_dot，其余明确几何和亮暗渲染由本项目实现。完整AnoStyler生成网络、SAM、CLIP和新权重未下载／运行。新模块与原实验数据、模型和阈值隔离。

## 数据与配置

旧AnoLCD split中的1840张预留正常训练文件，按原manifest RGB身份排除旧N／Vnew／Tfinal及排除图、合并同RGB后，得到1833个候选组；不把RGB组称为独立物理采集组。组ID排序后按PCG64种子20261014排列，每组取字典序第一文件，固定N_gen80、S_bg20、Q_cal40，共140张／140组。原manifest和源文件哈希核验；旧测试内容和标签未读入本次生成或推理。

24个请求在模型评分前固定，两类型各12、共12个几何配对，使用首4张N_gen背景，每对背景及随机种子一致，只改变标明的一个几何因素。4张背景为0191、2391、1146、1689的正常训练来源，不按图像观感或分数挑选。路径及身份见[data/controlled_generation/split.json](D:/华兴源创/实验/弱缺陷Demo/data/controlled_generation/split.json)；预定请求见[trial_requests.json](D:/华兴源创/实验/弱缺陷Demo/results/controlled_generation/trial_requests.json)。

全图RGB双线性缩放到256，float32/255，坐标以该网格像素中心为准。幅度固定为+0.04或-0.04，实际alpha受形状与边缘影响，不能把幅度参数当作每个像素实际变化。M_eff为最大通道绝对残差>float32(1/255)；PNG采用无损保存，并用量化图差>1码值另算有效标签。越界、退化、错误单位、空变化等条件拒绝，不静默裁切／当作正常训练样本。

## 实际结果与分母

| 核验对象 | 实际结果 | 解释 |
|---|---|---|
| 有效生成请求 | 24/24；Mura式12/12，线状12/12 | 仅这些预定请求有效，不是全分布成功率 |
| 实际覆盖率 | float和PNG均为100%，每例分母为其请求区域像素数 | 不是检测召回 |
| 请求区域外变化 | float最大0，PNG最大0码值 | 本轮背景保存一致 |
| float／PNG标签分歧 | 24例合计0像素 | 其他强度与背景下仍需复核 |
| 实际区域内最大RGB残差 | 所有请求合并范围约0.01031235—0.04000002 | float误差允许末位略高于0.04；实际约2.63—10.20个8位码值 |
| 重复生成与保存核验 | 24/24一致，无失败 | 相同输入、参数、种子及版本的CPU重算 |
| 无效条件拒绝 | 8/8 | 含越界、零面积／退化、错误单位、细线、零幅度及正白／负黑饱和消失 |
| 冻结PatchCore正常背景报警 | 0/4 | 4个唯一背景，非独立误报率估计 |
| 冻结PatchCore模拟图报警 | 24/24；两类各12/12 | 合成开发响应，非真实召回或训练收益 |

直线实际主方向相对请求角度的最大误差约0.121°，请求中心的最大质心偏差约0.0108个工作像素。线宽由像素中心到中心线距离控制；另报的面积/长度含圆端帽，只是宽度代理，不是精确横截面宽度。所有详细请求几何、有效区域及残差、裁切比例见[trial_results.json](D:/华兴源创/实验/弱缺陷Demo/results/controlled_generation/trial_results.json)。

检测器复用旧AnoLCD正式N80 PatchCore库，RGB256与原ImageNet归一化，原始整图分数和原Vnew阈值1.8928574562072753、严格大于报警。只对4个背景与24个float模拟图推理，共28图；模型不接收生成掩码，未重建库、未修改阈值、未打开真实测试图。4个背景分数约1.049—1.585；模拟分数约2.563—6.716。本次没有计算真实AUROC、真实召回或像素AP。

## 资源、运行与判断

实际环境为Python3.12.7、NumPy1.26.4、Pillow12.3.0、OpenCV4.11.0.86、SciPy1.16.2、Matplotlib3.11.2、imgaug0.4.0；已有torch2.8.0+cu128、RTX5060 Laptop约7.96GiB显存，RAM约15.62GiB，初核时可用约2.89GiB。生成用CPU，24例计算与保存约4.20秒；PatchCore加载与28图推理约3.85秒，CUDA峰值已分配约366.81MiB。Python／库启动及额外哈希核验另计，这些时长不能用于估算新训练。

可复制的PowerShell命令见[运行说明](D:/华兴源创/实验/弱缺陷Demo/controlled_generation/README.md)。已通过实际保存材料重算与独立只读核验；缓存消费前重新核验，绘图仅使用保存响应，不重跑模型。

本轮证明第一版生成接口可工作，标签与实际变化一致，旧检测器能对这些模拟变化报警。仍需改进和研究的部分是：面状场的边界较规则且有有限支持截断，弱Mura物理真实性未知；线状为亮暗外观模拟；单一幅度及4个背景无法代表缺陷分布。100%覆盖与报警不证明真实屏幕定位已解决。

下一步按两周方案先固定可接受的生成外观和G1采样条件，再准备训练侧8样本／1000步可学习性试跑；所有训练由用户手动运行。通过后再做公平G0/G1正式对照，新独立真实验证数据仍需用户手动取得及来源／标签／重复核验。此时不宣称生成带来训练收益或真实检测提升。
